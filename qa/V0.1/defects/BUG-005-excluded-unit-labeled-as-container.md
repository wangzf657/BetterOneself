# BUG-005 已排除学习单元在详情面板误标为"容器 · 0 / 0 点亮"

| 字段 | 内容 |
|---|---|
| 缺陷 ID | BUG-005 |
| 标题 | 已排除的学习单元详情面板显示"容器 · 0 / 0 点亮"，与其真实身份矛盾 |
| 模块 | B2-05 / P03 详情面板 |
| 严重级别 | P3 轻微（显示瑕疵；"已排除：历史记录只读，可恢复"说明正确） |
| 复现概率 | 必现 |

## 复现步骤
1. 工作树排除任意学习单元（如 1.1 什么是 Agent）。
2. 打开该节点详情面板。

## 预期结果
显示学习单元身份（未学/已点亮等）+ 已排除标记。

## 实际结果
显示"容器 · 0 / 0 点亮"+"已排除"。学习单元被排除后在 DTO 中 is_learning_unit=false（排除语义改变该字段），前端据此渲染成"容器"。证据：走查实录（qa/V0.1/03-test-cases.md B 区）。

## 影响分析
用户误以为该节点是分组容器、其下应有子节点，与"排除单个学习单元"的心智冲突；对排除已点亮节点场景更易困惑。

## 修复记录（2026-11-21）

- 根因：排除使 DTO `is_learning_unit=false`，详情面板据此渲染"容器 · 0 / 0 点亮"。
- 修复：`DetailPanel.tsx` 增判 `wasLearningUnit = excluded && 无 children`（排除的叶子节点本是学习单元），改显"学习单元（已排除）"徽章，原点亮者用金色（lighted_at 保留可见）；容器、未排除节点渲染不变。DTO 语义不动（排除仍是"移出有效学习路径"，工作树/进度口径不受影响）。
- 回归：前端 tsc/eslint 通过；pytest 59 passed，E2E 7 passed（含排除/恢复链路）。
