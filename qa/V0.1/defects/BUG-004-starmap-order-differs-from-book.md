# BUG-004 星盘视图章星排序与书序不符

| 字段 | 内容 |
|---|---|
| 缺陷 ID | BUG-004 |
| 标题 | 星盘视图未分组章显示在部分组之前，章节顺序与原书相反 |
| 模块 | B2-06 / P03 技能树（星盘视图） |
| 严重级别 | P3 轻微（导航理解困扰；工作树视图顺序正确可替代） |
| 复现概率 | 必现（存在部分层且其后仍有未分组章时） |

## 复现步骤
1. 导入含 5 章的 TXT（QA书-TX-01），桩规划把第 1–2 章组为"第一部分"。
2. 打开书页星盘视图。

## 预期结果
章星按原书顺序呈现：第一部分（第一、二章）在最前，其后第三、四、五章（页面清单 P03-C"存在部分层时，章星按部分分区呈现"）。

## 实际结果
顶部一行显示第三章、第四章、第五章，"第一部分（桩规划）"区域（含第一、二章）显示在下方，阅读顺序被颠倒。证据：qa/V0.1/screenshots/p03-tree-starmap-study9.png。

## 影响分析
新手以星盘为主要导航时，"从第一章开始"的心理预期被打乱；悬停"下一个"提示可部分缓解。

## 修复记录（2026-11-21）

- 根因：`StarMapView.buildGroups` 固定把散章组放在所有部分组之前，与书序相反。
- 修复：按书序原位排布——遍历 roots 顺序产出分区，连续散章在其书序位置成组（`loose-{首章id}` 键），部分组出现在其书序位置；无部分层书（单散章组）与无章层书（空盘回落工作树）行为不变。
- 回归：E2E 主链路（部分层书：第一部分在前、第三章在后）与规划失败保树用例（无部分层书）通过；pytest 59 passed，E2E 7 passed。
