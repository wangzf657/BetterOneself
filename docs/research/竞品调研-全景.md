# 竞品全景调研：闭源头部产品 + 同类开源项目 + 学习科学映射

> 调研时间：2026-11-18 | 方法：WebSearch + 官网抓取 + GitHub API 核实
> 说明：NotebookLM 官网在本网络环境直连超时，信息来自搜索摘要与第三方评测交叉验证；个别定价各来源有出入，已标注。

## 一、闭源竞品对比表

| 产品 | 定位 | 目标用户 | 资料导入 | 学习规划 | 复习/测验 | 督促机制 | 商业模式 |
|---|---|---|---|---|---|---|---|
| **NotebookLM** | 源文档驱动的"封闭语料推理引擎" | 大学生、研究者、知识工作者 | Docs/PDF/MD/网页/YouTube/音频；Discover sources 按主题自动找资料 | **无**（Learning Guide 模式只追问目标，不产出排期） | 闪卡+测验+学习指南+思维导图，均带源引用；**生成物一次性，无排程无追踪** | **无** | 免费；Plus 随 Google AI Pro（~$19.99/月） |
| **Khanmigo** | 苏格拉底式 AI 导师，绑定可汗课程体系 | K-12 | **不支持任意资料导入** | 依附 Khan Academy mastery 体系 | 分层提示链+练习题 | 弱 | $4/月或$44/年 |
| **StudyFetch** | 全能型 AI 学习平台（与我们最像） | 全球学生（自称 800 万+） | PDF/PPT/录像/拍照/YouTube；**可不传资料直接输入主题** | **有**：资料+截止日期→计划→里程碑→进度追踪 | 闪卡/测验/模拟考/游戏 | 弱（仅进度追踪，无主动推送） | 免费+Premium（月付约$19，年付约$8-10/月，各来源有出入） |
| **Turbo AI** | 课堂录音→笔记的 AI 学习工具 | 大学生 | PDF/视频/录音/YouTube/笔记 | 弱；预制 AP 指南库 | 闪卡/测验/开放问答，"无限刷题直到掌握" | 无 | 免费档+订阅 |
| **RemNote** | 笔记+间隔重复一体化 | 长期深度学习者 | 笔记内原生+材料生成卡片 | 无独立规划，复习排程即规划 | **最强**：SM-2+FSRS 双算法 | 复习队列到期即督促 | Free；Pro $10/月 |
| **Quizlet** | 卡片学习+题库社区 | K-12 与大学生 | 手动建卡+AI 闪卡生成 | 无 | Learn 模式（自适应+间隔重复） | 弱 | Free；Plus $7.99/月 |
| **Anki** | 极简间隔重复引擎 | 记忆密集型学习者 | 手动建卡；AI 靠第三方插件 | 无 | FSRS 已原生内置 | 到期卡片队列 | 免费/开源；iOS $24.99 |
| **Mindgrasp** | 讲座→笔记/闪卡/测验转换器 | 大学生 | 录音/视频/PDF/网页 | 无 | 闪卡/测验/摘要 | 无 | 约$9.99-19.99/月（未验证） |

**小结**：闭源侧三条路线——①"资料仓库"（NotebookLM，资料强教学法弱）；②"教学法"（Khanmigo，教法强不吃用户资料）；③"转换器"（StudyFetch/Turbo/Mindgrasp，导入→生成物，同质化严重拼价格）。**没有一家把"任意资料→规划→督学→排程复习"四环全部做通。**

## 二、头部竞品流程拆解

### 2.1 NotebookLM

```
新手引导（示例 notebook，三面板 Sources/Chat/Studio）
→ 导入（拖拽/URL；Discover sources 零资料冷启动）
→ 学习（Chat 带源引用；Learning Guide 先追问目标再输出；Audio/Video Overview 播客式深读）
→ 复习（Studio 生成闪卡测验，带源引用；生成物一次性，无排程无掌握度追踪）
```

**好**：引用锚定全场最佳（每个回答可点回源文段落）；Discover sources 解决冷启动；Learning Guide"先问目标再输出"产品化。

**缺陷（我们的机会）**：
- **导入后断崖**：不告诉你"下一步学什么、今天该学多少"
- 无时间维度：无考试日期、无排期、无到期队列，闪卡用完即弃
- 笔记本孤岛：跨 notebook 无统一掌握度档案
- 输出一致性差（相同 prompt 质量骤降的社区投诉）

### 2.2 StudyFetch（与我们方向最像）

```
导入（或输入主题零资料冷启动）→ AI 导师 Sparky 对话 → 资料+截止日期生成计划分解里程碑 → 闪卡/测验/模拟考/游戏追踪
```

**好**：链路完整度全场第一；主题驱动冷启动。

**缺陷**：
- 规划深度浅：本质是"里程碑列表+进度条"，不感知具体章节卡壳；计划不随测验结果重排
- 督促只有"查看进度"，无主动触达
- 无间隔重复："无限重复"而非 FSRS 排程，时间浪费在已掌握内容
- 用户讨论区常见"值不值这个价，还是直接用 ChatGPT"——转换器路线溢价困难

### 2.3 Khanmigo（教学法标杆，反面参照系）

```
依附 Khan Academy 课程 → 苏格拉底式（先作答→答错逐层释放提示→要求解释推理）→ 接入 mastery 体系晋级
```

**好**：先作答再提示、逐层释放、要求复述推理——Bloom 两西格玛与哈佛 Kestin et al.(2025, Scientific Reports，AI 导师学习增益约为课堂主动学习 2 倍)研究中"教学法护栏"的商业化样板。

**缺陷**：不吃用户自有资料；提示机制可被"连点提示拿到答案"绕过；离开可汗内容体系即失效。

**最重要的一课**：NotebookLM 有资料没教法，Khanmigo 有教法没资料，**"用户资料 + 可迁移的教学法护栏"这个交集就是我们的位置。**

## 三、同类开源项目盘点（除 OpenMAIC / DeepTutor）

| 项目 | Stars | 活跃度 | 定位 | 与我们的关系 |
|---|---|---|---|---|
| [RAGFlow](https://github.com/infiniflow/ragflow) | 94.3k | 极活跃 | 深度文档理解 RAG 引擎（DeepDoc 解析表格/版式）+ Agent 编排 | 基础设施候选：PDF/复杂文档解析可复用，不含学习法 |
| [AnythingLLM](https://github.com/Mintplex-Labs/anything-llm) | 68.4k | 极活跃 | MIT 全栈本地 RAG 工作台 | 架构参照系：纯问答、无学习闭环 |
| [Open Notebook](https://github.com/lfnovo/open-notebook) | 42.0k | 极活跃 | "更灵活的 NotebookLM 开源实现" | 直接对标的资料侧；止步于"问答+生成物" |
| [Khoj](https://github.com/khoj-ai/khoj) | 38.2k | 放缓（2026-08 后无 push） | "AI 第二大脑"，自定义 Agent + **定时自动化 automations** | 唯一有"主动定时任务"原型的开源项目，可借鉴督促 |
| [Onyx（原 Danswer）](https://github.com/onyx-dot-app/onyx) | 33.4k | 极活跃 | 企业知识平台，50+ 连接器 | 方向不同；连接器生态思路对"网页/GitHub 导入"有参考 |
| [Mr.-Ranedeer-AI-Tutor](https://github.com/JushBJJ/Mr.-Ranedeer-AI-Tutor) | 29.5k | **已停维护**（2025-09） | 纯 prompt 工程的 GPT-4 导师（可配置深度/风格/语气） | 早期证明"AI 导师"需求巨大；已死勿依赖 |
| [fsrs4anki / open-spaced-repetition](https://github.com/open-spaced-repetition/fsrs4anki) | 4.1k | 活跃 | FSRS 间隔重复算法官方库 | **核心依赖候选**：排程不必自研 |
| [Podcastfy](https://github.com/souzatharsis/podcastfy) | 6.8k | 一般 | NotebookLM 播客功能开源替代 | 非核心，Audio Overview 类功能可直接集成 |
| GitHub topics ai-tutor / study-assistant / study-planner | — | 零散 | 各自单点（自适应路线图/测验/RAG 问答） | **没有同时打通四环的项目** |

**结论**：RAG"资料侧"开源供给充足，"学习法侧"（规划/排程/督促）在开源世界几乎空白。没有与"伴学 Agent"完整方向直接对标的成熟开源项目——这个位置是空的。

## 四、学习科学理论映射

| 理论 | 要点 | 谁在用 |
|---|---|---|
| 间隔重复 SRS | 按遗忘曲线排程，FSRS 为当前最优开源算法 | RemNote（SM-2+FSRS）、Anki（原生 FSRS）、Quizlet Learn（轻量）；**NotebookLM/StudyFetch/Turbo 均无排程** |
| 主动回忆 | 提取式练习比重读高效，与 SRS 合称"ROI 最高的两件事" | Khanmigo 和 StudyFetch 的"先作答再反馈"做的是"实质" |
| 掌握学习 | Bloom 两西格玛问题（1984）：1对1掌握学习辅导高约 2 个标准差；哈佛 Kestin 2025 证明有护栏的 AI 导师可达显著增益 | Khan Academy 整套体系；StudyFetch"刷题直到掌握"；NotebookLM 完全没有 |
| 苏格拉底/费曼 | 不直接给答案、要求学习者输出解释 | Khanmigo（分层提示）；**费曼式"讲给 AI 听并让 AI 挑错"几乎无人产品化** |
| 认知负荷管理 | 分段呈现、控制信息密度 | 各产品普遍缺席 |

## 五、市场空白/机会点

1. **"导入后断崖"是全行业通病**：导入 30 份 PDF 后的第一问永远是"然后呢"——没有一个产品以"计划"作为导入后的第一产出
2. **规划与资料脱节**：通用 planner 只看 deadline 不看内容；RAG 工具知道内容不知道时间。**基于资料结构（章节/概念依赖）排课没人做**
3. **督促机制集体缺失**：所有产品都是"打开才存在"。把"学习计划+主动触达"绑定成产品核心的，一个都没有
4. **复习不闭环**："AI 导师讲解产生的薄弱点自动变成 FSRS 卡片"这个环，闭源开源都没有
5. **掌握度档案无人建立**：跨会话、跨主题的"每个知识点掌握状态"数据结构不存在
6. **GitHub 仓库作为学习资料基本空白**：NotebookLM 不支持 repo 导入；"以 repo 为教材"只有玩具级供给
7. **独立对话式 AI 导师是死亡赛道**：Quizlet Q-Chat 2025-06 下线、Mr.-Ranedeer 停维护——纯 chat tutor 无独立留存价值，必须附着在结构化学习流上

## 六、对我们的启示（按优先级）

1. **把"计划"做成导入后的第一屏**：导入完成即产出资料结构拆解→概念依赖→按 deadline/每日时间排的日历；计划项锚定源文引用
2. **复习引擎直接用 FSRS，不自研排程**：AI 生成的闪卡/测验自动入队；错题自动转化为"AI 重新讲解"事件并回灌新卡片——"讲解→卡片→排程→薄弱点→再讲解"闭环是护城河级差异点
3. **督促机制 = 计划的执行器**：最小三件套——今日任务推送、逾期自动重排（重排而非堆叠）、每周掌握度复盘
4. **对话加"教学法护栏"但做成可调开关**：默认苏格拉底模式，提供直答模式开关；护栏必须附着在"计划-练习-复习"结构流之上
5. **建立跨会话掌握度档案**：以知识点为粒度记录掌握状态——这是垂类路径沉淀的数据前提
6. **资料导入差异化：GitHub 仓库 + 网页 + Markdown 原生**：与首批用户（程序员）高度重合
7. **警惕转换器路线的功能军备竞赛**：主线只有"计划-督学-排程复习"闭环，播客等生成物用开源方案后补
8. **垂类路径以"模板化计划+内容包"沉淀**：内置知识点图谱+卡片库+节奏参数，用户资料做血肉——可复用、可运营
