# 竞品调研：OpenMAIC

> 调研对象：[THU-MAIC/OpenMAIC](https://github.com/THU-MAIC/OpenMAIC) | 数据快照：2026-11-18
> 43,838 stars / 6,751 forks / MIT 许可证 / 2026-03-11 开源 / 更新极活跃（约每两周一个版本）
> 信息来源：仓库 README、`packages/docs` 官方文档、arXiv 论文 2409.03512、清华官网报道、GitHub API

## 1. 产品定位

**一句话**：OpenMAIC（Open Multi-Agent Interactive Classroom）是把**任意主题或文档一键转化为"AI 教师 + AI 同学"多智能体授课的沉浸式互动课堂**的开源平台——含幻灯片讲解、语音、白板、测验、模拟实验和项目制学习。

- **目标用户**：自学者（"教我量子物理"式一句话学习者）、教师/课程设计者、自部署的教育机构和开发者
- **核心理念**：源自论文《From MOOC to MAIC》(arXiv:2409.03512, JCST 2026)——MOOC 实现了规模化但牺牲了个性化，MAIC 用 LLM 多智能体重建"课堂"形式，兼顾**规模化与因材施教**，即"一人一课堂"
- **团队**：清华大学 MAIC 团队；截至 2026-08 底：58 万+ 创作者、100 万+ 门生成课程、3400 万次 AI 交互、覆盖 154 个国家和地区

## 2. 核心功能清单

| 功能 | 说明 | 成熟度 |
|---|---|---|
| 一键课堂生成 | 输入主题或上传材料（PDF/Word/PPT/表格/文本/图片/音视频），先生成大纲 → 再逐场景生成 | 成熟 |
| 多智能体课堂 | AI 教师授课 + AI 同学参与；课堂讨论、圆桌辩论、自由问答 | 成熟 |
| 四种课堂场景 | 幻灯片（语音讲解+聚光灯）、测验（单选/多选/简答+AI 批改）、HTML 交互模拟、PBL 项目制学习 | 成熟 |
| 深度交互模式 | 3D 可视化、过程模拟、知识小游戏、思维导图、在线编程；AI 教师可主动操作 UI 引导 | 较成熟 |
| 白板 + 语音 | Agent 实时白板推导；多 TTS 供应商，自托管支持声音克隆；ASR 语音提问 | 成熟 |
| 知识库 | 上传材料持久保存、文件夹管理、@-提及引用 | 较新（v1.3.0） |
| Agent 工作台 | 对话式课程构建 Agent：规划 curriculum、原子化编辑、24 个内置教学风格 skill、课程级 undo | 较成熟 |
| 联网调研 | 课中/生成中联网搜索 + 网页抓取阅读 | 较新 |
| 导出 | PPTX、单文件离线 HTML、课堂 ZIP（跨部署迁移）、MP4 视频 | 成熟 |
| 模型接入 | Provider 中立，20+ 供应商；"slot"机制按用途分别指定模型；支持 BYO Token | 成熟 |
| 外部 Agent 集成 | 标准 SKILL.md，可从飞书/Slack/Telegram 等 20+ 聊天应用直接生成课堂 | 较新 |

## 3. 用户使用流程

1. **进入首页** → 一个输入框：输入主题或拖入参考资料
2. **材料解析**（可选）→ 材料入库到个人知识库
3. **生成大纲** → 结构化课程大纲（用户可编辑）
4. **逐场景生成** → 幻灯片/测验/交互模拟/PBL；服务端生成，关浏览器不中断
5. **进入课堂播放** → AI 教师语音讲解；学生随时打断提问，可被点名；可发起圆桌辩论
6. **课中互动** → 测验即时批改；交互模拟动手实验；PBL 按里程碑协作
7. **完成后** → 课程完成页总结；课程进入"我的课程"库
8. **迭代编辑** → 手动编辑或 "Edit with AI"
9. **导出/分享** → PPTX / 离线 HTML / ZIP / MP4

旁路入口：在飞书/Telegram 等聊天应用里 @助手说"教我 X" → 异步生成 → 返回课堂链接。

## 4. 学习科学 / 教学法设计

有学术论文支撑，但偏向"课堂社会性"而非"记忆科学"：

**有明确依据**：
- 因材施教/个性化（产品出发点）
- 主动回忆/形成性评价：课中嵌入测验 + AI 实时批改；论文访谈中"测验被多名学生认为是知识吸收的关键环节"
- 建构主义/探究式学习：模拟实验、在线编程"做中学"
- **课堂社会临场感（差异化亮点）**：AI 同学 4 种人设——Class Clown（活跃气氛）、Deep Thinker（挑战性问题）、Note Taker（总结要点）、Inquisitive Mind（主动提问）
- 实证数据（清华，500+ 学生、10 万+行为记录）：61% 课内行为是主动提问；课内消息量与测验/期末成绩显著正相关（r=0.341）

**明确缺失**（与"伴学"场景强相关）：
- 间隔重复/记忆曲线：**无**，学完即结束，无复习系统
- 费曼技巧/输出式学习：**无**
- 掌握学习：**无**，测验不阻断后续进度
- 长期学习规划/督学：**无**
- 个性化 learner model：论文实验最低分恰是"帮助认识强弱项的反馈"（3.51/5）——所有学生共用同一份生成脚本

## 5. 产品架构的产品视角

- **课程 = 可播放的舞台剧**：Course 由有序 Scene（幻灯片/测验/交互/PBL）组成，是全产品核心数据契约
- **Agent 分两层**：课内"演出班底"（教师+同学+隐藏的 Manager 调度）；课外"编剧团队"（课程构建 Agent）
- **知识库 = 独立于课程的材料资产层**：@-提及实现"一次导入，多处复用"
- **能力 = Slot 插槽**：按用途（大纲/正文/TTS/图像/搜索）分别指定模型，供应商中立
- **对外扩展 = Skill 包**：让任何外部 Agent 工作台都能调用它，OpenMAIC 退化为"课堂生成引擎"

## 6. 亮点与不足

**亮点**：
1. "一句话→完整课堂"的生成体验，输入门槛极低
2. AI 同学多角色人设——用社会临场感解决"网课孤独感"，有论文实证
3. 超越视频的"场景化"知识呈现；主动提问行为与成绩正相关
4. 导出生态完善（离线 HTML/PPTX/ZIP），"学习资产可携带"做到位
5. 开放的供应商策略 + 本地推理支持 + MIT 协议 → 3 个月 43k+ stars
6. 学术-产品闭环，论文披露真实实验数据（含负面发现）

**不足**：
1. **学习闭环止于"下课铃"**：无复习、无错题本、无学习计划、无长期追踪——典型"课堂产品"而非"学习伴侣"
2. 个性化反馈是自我承认的短板（最低分 3.51/5），无跨会话 learner model
3. 学生实际偏好被动"连续模式"——互动响应不足会把学生推向被动
4. 自部署门槛高（Node 22 + pnpm + PostgreSQL + 多个 API key）
5. 生成质量强依赖模型档位
6. 无完整中文深度文档；hosted 版定价未公开

## 7. 对我们的启示

1. **把"下课铃短板"做成主战场**：它验证了课中互动价值但学完即止——我们以"课后陪伴"为轴心：对话/测验产生的错题自动沉淀为记忆卡片 + 间隔重复排程，形成"学习→遗忘→复习"完整闭环
2. **借鉴多角色 AI 同学，但吸取教训**：互动响应必须及时，否则用户退回被动；做不到秒级响应，宁可用"AI 同学定期主动冒泡"而非"可打断的实时辩论"
3. **个性化反馈作为北极星**：OpenMAIC 用户最低分项恰是"帮我认识强弱项"——跨会话 learner model 是核心差异化
4. **输出富"学习对象"，不做纯聊天流**：结构化场景（知识卡、内嵌小测、导图）比聊天记录更适合学习
5. **开放策略可"抄作业"但要区分商业边界**：BYO-Token + 多供应商是社区增长引擎
