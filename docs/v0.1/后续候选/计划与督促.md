# 后续候选：计划与督促

> 状态：**延后，不属于 V0.1 最薄闭环**。来源：V0.1 范围收缩（2026-11-20），原 B3-02/03、B7 与原学习首页方案。
> 当前实现不得据此提前建表或加入口。

## 目标

把"想学完这本书"落成可执行的分日计划，并在中断后无痛恢复。

## 需求要点（收缩前已评审）

- 目标访谈三问：目标、期限、每日可用时间；可跳过并使用明示默认值；
- 分日计划草案：遵循目录顺序、每日时长与期限；超期明确警告并给调整入口；确认后生效；可增删、改期；
- 逾期任务自动重排而非堆积；长期中断经确认后"回炉"，优先处理高风险记忆；
- 每日摘要（有学习行为才生成）与周复盘；复盘建议经确认才调整计划；
- 章强度三档（略读 / 读透 / 学透）：强度是任务形态与完成判定的硬约束。

## 评审增强（2026-11-20 产品评审）

- 目标访谈增加"通常什么时候、在哪学"一问，计划任务带时间地点提示——执行意图（implementation intentions，d=0.65，Gollwitzer & Sheeran 2006），动机文献中效应量最大、成本最低；
- 周复盘从"完成率 + 建议"改为**进步叙事**：本周通过 X 个节点（上周 Y）、高风险卡 N→M、距全书点亮还剩 Z——能力证据可视化比完成率更能维持动机；
- 章默认"学透"是重承诺，访谈时应展示代价（预计天数 × 分钟、测验次数），让强度选择是知情选择。

## 依赖与重启前置条件

1. 最薄闭环（导入 → 骨架 → 学 → 测 → 点亮）已用真实书验证有持续驱动力；
2. [复习与卡片](复习与卡片.md)先行或同期：逾期重排的"高风险优先"依赖复习数据；
3. 点亮语义升级（当前通过 → 含保持验证）后再定义强度分母。
