# 后续候选：学习增强

> 状态：**延后，不属于 V0.1 最薄闭环**。来源：V0.1 范围收缩（2026-11-20），原 B4-02 选段操作、B9-03 扩展与 2026-11-20 产品评审建议。
> 当前实现不得据此提前建表或加入口。

## 目标

在闭环成立后，提升单位学习时间的记忆与迁移效果。

## 候选条目

| 条目 | 说明 | 依据 |
|---|---|---|
| 前测小问题 | 进入节点讲解前先来一道允许猜的小问题，错了也涨记忆 | 前测效应（Pan 2023） |
| 按掌握度切换讲解（fading） | 新节点先讲解 / 示例，接近达标时改为"你先答、AI 后评"；承载于三学习方法 | worked example 与专长反转（Kalyuga 2007） |
| 会话内通过进度条 | 会话页头显示"讲解 ✓ 提问 ✓ 测验 □"，让"离点亮还有多远"可见 | 目标梯度效应 |
| 碎片 3 分钟快测 | 碎片场景做几道同章交错题，替代"只能清卡" | 交错 + 提取练习 |
| 整本原文阅读页 | 独立阅读器：章内滚动、搜索、选段"就这段提问 / 保存为卡片" | 原收缩前 P05 |
| 手动建点与拆分合并 | 无目录书手动创建学习单元；既有节点拆分、合并、移动，编辑不丢证据 | 原收缩前 B2-05 全量 |
| 即时给答案的出口 | "带我学"引导思考时，用户明确要答案就立刻给，不坚持绕弯 | Khanmigo RCT：学生绕开不给答案的导师，参与度才是瓶颈 |

## 依赖与重启前置条件

1. 最薄闭环已验证驱动力；增强项逐个评审再进版本，不整包搬入；
2. 选段保存为卡片依赖 [复习与卡片](复习与卡片.md)。
