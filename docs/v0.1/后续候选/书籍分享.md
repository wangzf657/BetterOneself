# 后续候选：书籍分享

> 状态：**延后，不属于 V0.1**。本文只保存已讨论的简单方向，当前实现不得据此提前建表或加入口。

## 目标

把一方已经整理好的书快速交给另一方使用：不必重新解析正文、生成向量或运行目录规划，即可开始自己的学习。初期用于产品体验，后续可支持人与人之间互相分享。

## 最小形态：一个书包文件

采用单个 `.zip` 文件，导出与导入都在本机完成，不需要账号或在线社区。

```text
book-pack.zip
├── manifest.json       # 格式版本、书名、导出时间、内容清单与校验信息
├── source/             # 原始主文件
├── chunks.json         # 正文切片与定位
├── vectors.bin         # 向量及与切片的对应关系
├── outline.json        # 目录、知识点、引用、强度与调整记录
└── cards.json          # 已整理卡片
```

`manifest.json` 至少包含：

```json
{
  "schema_version": 1,
  "book_title": "……",
  "source_file": "source/book.pdf",
  "embedding_model": "BAAI/bge-m3",
  "embedding_dimensions": 1024,
  "contents": ["source", "chunks", "vectors", "outline", "cards"]
}
```

## 导入语义

- 导入后成为一个新的独立学习项目；
- 所有内部 ID 重映射，导入在单事务中完成；
- 原文、切片、向量、目录和卡片直接恢复，不消耗接收方重复解析与向量化成本；
- 接收方从自己的计划与掌握档案开始学习；
- 默认不导入原分享者的个人测验历史、复习排程、每日摘要和掌握档案；
- 同一包重复导入可并存，不做版本合并与远程同步；
- 格式或向量模型不兼容时明确拒绝，不静默生成坏数据。

## 安全与边界

- zip 解包必须防路径穿越与异常大小；
- 包内不包含任何 API Key、用户设置或本机绝对路径；
- 分享者应在导出前知道卡片可能包含自己的学习笔记；
- 后续若做社区，也只解决发现与分发，不改变书包的独立导入语义。

## 重新启动该候选的前置条件

1. V0.1 的自导入闭环已经用真实书验证；
2. 书包格式用两个不同环境完成一次导出 → 导入 → 学习验证；
3. 再讨论是否需要下载链接、分享列表或社区，不提前设计账号与运营体系。
