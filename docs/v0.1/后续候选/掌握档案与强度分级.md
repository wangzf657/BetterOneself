# 后续候选：掌握档案与强度分级

> 状态：**延后，不属于 V0.1 最薄闭环**。来源：V0.1 范围收缩（2026-11-20），原 B3-01、B3-04、B8。
> 当前实现不得据此提前建表或加入口。

## 目标

回答"凭什么说学透"：证据分层、口径透明、可回退，并把用户的学习目标纳入最终判定。

## 需求要点（收缩前已评审）

- 章强度三档为硬约束：略读看显式读完、读透看章末费曼复述、学透看全部有效知识点通过且关联卡无高风险；
- "我已掌握"自评与系统评估分开，自评须经一道不泄露答案的快速验证，且永不作为通过证据；
- 掌握档案按目录树展示证据时间线（测验 / 复习 / 复述），可下钻、可回看；
- 进度可回退：高风险出现后节点退出有效通过，章与全书同步下降，历史证据保留；
- 结业报告达到条件后生成，真实下载。

## 评审增强（2026-11-20 产品评审）

- **结业报告改为"目标 vs 达成"叙事**：对照导入时写下的学习目标、首次与最近测验对比、遗留薄弱点清单与建议——数月旅程的终点应有仪式感与自我效能证据；
- **应用型结业任务**：结业（或章末）增加面向学习目标的小练习 / 小项目，AI 依据书中内容出题与评审——当前全部证据只检验"记得 + 能复述"，证明不了目标里写的"会用"（程序性知识走卡片无效，Carpenter 2022）；
- "我已掌握"快速验证从一道四选一（猜对率 25%）升为 2–3 题或一道简答；
- 元理解偏差支持现状：自评不作证据、证据式判定（IOED，Rozenblit & Keil）——维持原设计。

## 依赖与重启前置条件

2. 导入流程重新收集学习目标（最薄闭环已移除该字段）。
