# V0.1 数据模型

> 日期：2026-11-20｜状态：目标设计，未实施（从零建库，无旧数据兼容——决策 #24 清零）
> 产品依据：[需求列表](../product/需求列表.md)（B1-01…B5-04）
> 配套：[技术方案](技术方案.md)、[流程图](流程图.md)、[接口设计](接口设计.md)

## 1. 建库策略

- 空库起步，Alembic 单个 init revision 建全部表与 sqlite-vec 虚表；
- 单机自用：schema 演进允许破坏性重建 + 手动重导入，不写增量兼容迁移；
- 知识点是数据枢纽：会话、测验、笔记、点亮全部通过 `kp_id` 关联，检索切片（chunk）不是学习单位。

## 3. 表结构

| outline_error | TEXT NULL | 规划失败原因（未配置也在此说明） |

`chunk_id` PK FK→source_chunks.id CASCADE + sqlite-vec 虚表列 `embedding`（bge-m3，1024 维 float32）。重解析时先删旧向量再写新向量，避免脏稳态（注意事项 #9）。

| 列 | 类型 | 说明 |
|---|---|---|
| id | PK | |
| study_id | FK CASCADE | |
| parent_id | FK self NULL | 根为 NULL |
| name | TEXT NOT NULL | |
| sort_order | INTEGER NOT NULL | |
| is_chapter | BOOLEAN NOT NULL DEFAULT 0 | 章锚点：初始识别后固定，AI 不可删章（B2-03） |
| origin | TEXT NOT NULL | toc / heading / ai_split / ai_merge / ai_organize / ai_group / manual |
| confidence | REAL NOT NULL | 0–1，识别置信度（B2-02） |
| confidence_basis | TEXT NOT NULL | 识别依据：原书目录 / 标题规则 / AI 规划 / 用户修改 |
| excluded | BOOLEAN NOT NULL DEFAULT 0 | |
| exclusion_reason | TEXT NULL | 可选原因（B2-05） |
| planning_note | TEXT NULL | AI 调整理由 |
| chapter_summary | TEXT NULL | 章内容摘要，仅 `is_chapter=1` 有值（拟大纲时按四问模板生成，chat 作书级地图复用） |
| lighted_at | TIMESTAMP NULL | **点亮时间：非空即已点亮；一次写入永久保留**（B4-03） |
| created_at / updated_at | TIMESTAMP | updated_at 仅用户编辑触发（AI 写 chapter_summary / planning_note 不触发），是规划冲突比对依据 |

节点三态（B2-06）全部派生，不落字段：

- **已点亮**：`lighted_at IS NOT NULL`；
- **学习中**：未点亮 ∧ 该节点会话存在消息；
- **未学**：其余。全部节点开放，无解锁门槛（决策 #20）。

### 3.6 knowledge_refs

`id` PK、`kp_id` FK CASCADE、`chunk_id` FK→source_chunks RESTRICT、`sort_order`。引用挂载提交是拟大纲应用的前置条件；节点 refs ≥ 1 才能开始学习与测验。

结构识别、AI 规划与用户编辑的完整历史都在本表（P03-E 抽屉数据源）。

### 3.8 sessions

`id` PK、`study_id` FK CASCADE、`kp_id` FK CASCADE **UNIQUE**（节点 1:1 持久会话，取或建幂等）、`scheme`（会话内可切换，只影响本会话）、`created_at / updated_at`。

### 3.9 messages

| 列 | 类型 | 说明 |
|---|---|---|
| id | PK | |
| session_id | FK CASCADE | |
| role | TEXT NOT NULL | user / assistant |
| content | TEXT NOT NULL | Markdown |
| refs_json | TEXT NULL | 引用列表：chunk_id + 定位 + 被引文本（角标点击回跳） |
| created_at | TIMESTAMP | |

测验卡不是消息：`quizzes` 挂 `session_id`，会话详情把 messages 与 quizzes 按 `created_at` 合并渲染对话流，避免双写。开场讲解是首条 assistant 消息。

### 3.10 quizzes

| 列 | 类型 | 说明 |
|---|---|---|
| id | PK | |
| study_id / kp_id / session_id | FK CASCADE | 证据链：点亮下钻到 quiz（B5-01） |
| questions_json | TEXT NOT NULL | 下发面：题型（choice / short）、题干、选项；**不含答案**（B4-01） |
| answers_json | TEXT NOT NULL | 服务端持有：答案、解析、来源 refs；提交前任何响应不包含 |
| pass_line | INTEGER NOT NULL | 通过线，生成时定且不得中途变（B4-02） |
| correct_count | INTEGER NULL | 判分后写 |
| passed | BOOLEAN NULL | 判分后写 |
| created_at / answered_at | TIMESTAMP | answered_at NULL 即未提交 |

去重（B4-02 反例）：生成时查询该 kp 全部历史 `questions_json` 的题干列表传入 quiz skill 排除；生成后做题干完全重复检查，重复则重试一次。

### 3.11 notes

`id` PK、`study_id` FK CASCADE、`kp_id` FK CASCADE **UNIQUE**、`content_md` TEXT（64KB 上限）、`created_at / updated_at`。upsert 幂等；不参与点亮与任何统计（决策 #26）；节点顶部位置行由前端从树数据渲染，不存正文。

### 3.12 settings

`key` TEXT PK、`value` TEXT、`updated_at`。键：`llm.base_url / llm.model / llm.api_key`（Fernet 加密）、`embed.base_url / embed.model / embed.api_key`（加密）。点亮反馈偏好（音效/动效开关）是前端偏好，localStorage，不落库。

### 3.13 usage_days

`id` PK、`date`（YYYY-MM-DD）、`scene`（outline / tutor / quiz / embed）、`requests / prompt_tokens / completion_tokens`，UNIQUE(date, scene)。写入失败不得静默吞掉（注意事项 #9）。

## 4. 点亮进度口径（B5-01）

```
有效节点（分母） = 叶子（无未排除子节点）
                ∧ origin ≠ 'ai_group'        # 部分层只是分组，永不进分母
                ∧ 自身及全部祖先未排除
                ∧ knowledge_refs ≥ 1          # 无引用节点无法学习与测验，不进分母
progress = count(lighted_at IS NOT NULL ∧ 有效节点) / count(有效节点)
分母 = 0 → progress = null（前端显示「—」，不显示 0%）
```

- 无引用节点待拟大纲拆分挂引用后自然进入分母，不需要人工干预；
- 每个进度数字可下钻：已点亮节点 → 该 kp 的 passed quiz（题面、得分、通过线、时间）；
- **分母变化必须透明**：排除、恢复、解散分组、恢复原目录写 `outline_events`，detail_json 带 leaves / lighted / percent 前后值（B5-01 反例：不得静默美化）；
- 进度实时计算，不落缓存列。

## 5. 点亮语义（B4-03，决策 #19）

- quiz 判分 `passed=true` → 同事务写 `kp.lighted_at`（若为 NULL；已点亮不重复写、不刷新时间）；
- 永久保留：任何流程不得清空 `lighted_at`；唯一级联清除是删除整本书；
- 重命名不改点亮；排除已点亮节点：证据原样保留、只出分母，恢复后回分母；
- 打开会话、阅读、自由提问、未通过测验都不写 `lighted_at`——点亮只有测验通过一条路径；
- 全站口径文案统一：「点亮 = 节点测验当前通过，不含长期记忆验证」。

## 6. 结构编辑不变量（B2-05，决策 #6/21）

用户手动编辑仅五种，其余结构操作是 AI 拟大纲产物（决策 #21）：

1. **重命名**：只改 name，写 kp_renamed 事件；原名保留在事件 detail_json；点亮与会话不受影响；
2. **排除/恢复**：只改 `excluded / exclusion_reason` + 写事件（带分母前后值）；不动 sessions / messages / quizzes / notes / lighted_at；
3. **解散部分分组**：删 group 节点，子章 parent_id 上移一级；学习数据零变动；
4. **恢复原目录**：以 `structure_built` 快照重建结构。`shortcut: 仅在无任何学习证据（会话消息数为 0）时可用，否则 422 并提示改用逐个排除, 学习中途需要精细回滚时升级为按调整逆放`；
5. AI 规划应用：按 `kp.updated_at` 比对，用户编辑过的节点跳过（用户优先）。

## 7. 删除与级联

- 删除整本书：CASCADE 清除全部关联（前端先弹影响清单：会话数、测验数、点亮数）；
- 删除单节点：不提供——排除取代删除，保证证据可恢复（B2-05 反例）；
- 重解析：删旧 chunks / vec_chunks 重建；knowledge_refs 按新切片重挂；节点、会话、测验、笔记、点亮不动。
