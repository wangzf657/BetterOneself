# V0.1 页面清单

> 日期：2026-11-20｜状态：高还原产品交互规格，范围收缩后
> 上游：[需求分析](需求分析.md)、[需求列表](需求列表.md)｜视觉线框：[原型设计](原型设计.md)
> 本文描述页面、内容、状态与操作，不规定接口、字段或技术组件。

## 1. 信息架构与全局约定

### 1.1 一级导航

桌面端顶部固定导航：

```text
BetterOneself｜我的书　　　　　　　　　　　学习方法 ?　设置
```

- **我的书** `/studies`：书架，也是首页；访问 `/` 重定向到本页；
- **设置** `/settings`：服务、用量与危险操作；
- **学习方法**：全站问号按钮，打开说明抽屉，不改变当前页面状态。

学习会话从树进入、用面包屑返回，不占一级导航。当前导航有明确选中态。

### 1.2 路由清单

| 编号 | 页面 | 路由 | 主要需求 |
|---|---|---|---|
| P01 | 添加一本书 | `/studies/new` | B1-01～03 |
| P02 | 我的书 | `/studies` | B5-01 |
| P03 | 书页·技能树 | `/studies/:studyId` | B2、B5-01 |
| P04 | 学习会话 | `/studies/:studyId/learn/:nodeId` | B3、B4（含 B3-05 笔记） |
| P05 | 设置 | `/settings` | B5-02～04 |
| — | 学习方法抽屉 | 全站覆盖层 | B3-03 |

### 1.3 全局反馈

| 状态 | 表现 |
|---|---|
| 页面加载 | 保留页面骨架，不白屏；超过 8 秒显示"仍在处理，可稍后刷新" |
| 局部保存 | 按钮进入"保存中…"；成功后原位更新，不强制跳页 |
| 成功 | 轻量提示说清结果，例如"4.2 上下文工程 已点亮"，不用"操作成功" |
| 可恢复失败 | 原位显示原因与"重试"，保留用户已填写内容 |
| 删除 | 弹窗列出会受影响的会话、测验与点亮状态；输入书名确认仅用于删除整本书 |
| 离线 / 服务断开 | 顶部持续条提示，已显示内容仍可阅读 |

toast 不替代页面内真实状态：点亮、排除等结果必须能在对应页面再次核实。

### 1.4 引用与原文定位

统一引用样式为带序号的小角标 `[1]`。学习会话内点击后，原文框滚动到对应段落并高亮；原文框处于收起状态时自动展开再定位；位置不可用时显示所在章与来源文本，不跳空白页。

### 1.5 通用空态原则

每个空态都回答三件事：**为什么为空、现在能做什么、做了以后会得到什么**。禁止只写"暂无数据"。

## P01 添加一本书 `/studies/new`

### 页面目标

一次流程完成"书名 + 文件"，并理解接下来会看到技能树。

### 布局

最大宽度 760，居中。表单按顺序：

1. **书名 / 学习项目名**，必填；选择文件后可自动带出去扩展名的文件名，仍可编辑；
2. **选择主文件**，必填；拖拽区与"选择文件"按钮；不支持格式在提交前直接提示；
3. 辅助文案："仅支持 EPUB、TXT、PDF、Markdown；每本书一个文件。"
4. 主按钮"导入并查看技能树"；次按钮"取消"。

### 提交与进度

提交后留在本页，出现分步状态：

```text
✓ 文件已保存
→ 正在解析正文与目录
○ 自动目录规划（可跳过）
```

- 解析失败：显示可读原因与"重试解析""更换文件"；
- 目录规划失败：不算导入失败，提示"已保留识别出的目录"，仍可进树；
- 基础目录可用后主按钮变为"查看技能树"，不等 AI 规划结束；
- 若文档没有可用结构，进入树页专门空态（见 P03-F），不自动全文拆解。

### 异常与反例

- 重复点击不得生成两本书；
- 离开进度页可从"我的书"回到同一进度；
- 未配置文件服务不阻止基础目录识别。

## P02 我的书 `/studies`

### 页面结构

页头"我的书" + 主按钮"添加一本书"。标签"学习中 / 已归档"，默认学习中。

每本书一张横向卡片：

- 书名、格式；
- 点亮进度（如 `● 12 / 178`）或"不适用"；
- 最近学习时间与上次节点；
- 主按钮"继续学习"（回到上次节点，没有历史则进入树的第一个未点亮节点）；
- 次按钮"查看技能树"；卡片菜单：归档 / 恢复、删除（删除显示影响清单）。

### 空态

- 无书时给添加引导："从一本书开始，看到技能树，点亮第一个节点"；
- 解析失败的书保留卡片、显示原因与"重试"，不得从列表消失。

## P03 书页·技能树 `/studies/:studyId`

这是本版最重要的页面：一眼看清这本书长什么样、学到哪了、下一步点亮哪个。

### A. 页头

```text
← 我的书
AI Agents in Depth                    ● 12 / 178 已点亮    [口径 ?]  [···]
继续上次：4.2 上下文工程（学习中）                          [继续学习 →]
```

- 大数字为点亮进度；`口径`打开抽屉："点亮 = 节点测验当前通过，不含长期记忆验证；已排除节点不计入；复习体系在后续版本加入"；
- 书名下可显示全书总述一句话（AI 拟大纲产物，悬停展开各部分如何推进）；未生成时不显示、不留空占位；
- `···` 菜单：重命名书、归档、导出（后续）、删除。

### B. 状态条

按实际状态显示一种：

| 状态 | 文案与操作 |
|---|---|
| 结构识别中 | "正在读取原书目录…"，显示已识别部分 |
| 原文与引用准备中 | "原目录已可查看，正在准备可回跳的原文"；拆分、合并等结构调整等引用就绪后应用 |
| AI 规划中 | "正在按书的逻辑拟大纲，原目录仍可编辑"，完成后标明每处调整 |
| 未配置 AI | "未配置 AI，已保留原书目录；可手动排除，或稍后配置重试" |
| 规划失败 | "目录规划未完成，原目录未受影响" + 原因 + 重试 |
| 规划完成 | "已拟大纲：4 个部分、排除 18 项、拆分 6 处、合并 12 处"（无部分分组时省略该段）+ 查看调整 |
| 低置信度 | "部分层级由标题样式推断，请检查标记节点" |

### C. 主工作区：双视图

工具栏含视图切换「星盘 ｜ 工作树」，默认星盘，选择按书记忆。两个视图共享右侧详情面板。

**右侧详情面板（两视图通用，选中节点后显示）**：

1. 面包屑路径；
2. 名称与状态；
3. **来源与识别**：原书目录 / 标题推断 / 用户修改 / AI 规划，附置信度与调整原因；
4. **学习数据**：最近测验结果与时间、通过线、点亮时间（如有）；
5. **原文引用**：对应段落位置，点击进入会话原文面板；
6. 主动作："开始学习 / 继续学习"或"重新测验"（结果不改变已点亮状态，口径同上）。

**星盘视图（默认，负责进度仪式与导航）**：

- 存在部分层时，章星按部分分区呈现（区域带部分名标签）；无部分层时直接平铺章星；具体视觉随原型评审定，不阻塞工作树能力；
- 章星卡片：星环 = 章内点亮进度（如 5 / 9）；满点亮章戴金冠；
- 当前章呼吸蓝光；悬停章星显示"下一个：节点名"；
- 已排除章置灰保留、可恢复；
- 点章星进入**章内路径**：纵向蜿蜒路线，起点在底部；叶节点按学习顺序排布，父节点作为路段名标注；
- 路径段状态：已走段金色流光、未走段暗虚线；学习中节点呼吸蓝光；路径默认滚到当前进度节点；
- 点任意节点 → 右侧详情；章尾提供"返回星盘 / 下一章"。

**工作树视图（操作台，负责全部整理操作）**：

- 缩进树 + 搜索框、展开全部 / 折叠到章、筛选"全部 / 已排除"；顶层可为部分层节点（来源标记"AI 规划"），悬停 `···` 可排除整组或解散分组；
- 树节点行：展开箭头、名称（最多两行）、状态徽标（未学灰空心 / 学习中蓝 / 已点亮金实心 / 待确认琥珀点 / 已排除灰 + 删除线）、章节点"3 / 8"点亮计数、悬停 `···`（重命名、排除 / 恢复）。

**动效与仪式（全树通用）**：

- 点亮瞬间：一次金色粒子（约 0.6s，一次即止）→ 路径连线流光点亮 → 节点变金色实心；
- 整章点满：章星星环填满动画 + 戴金冠，星盘给一次更大的粒子仪式；
- 常驻动效仅两种：学习中节点 / 当前章的呼吸微光、已走路径低速流光；
- 音效默认关，设置可开；动效尊重系统"减少动态效果"（退化为一次状态变化）；所有动效不得拖慢滚动与视图切换。

### D. 编辑弹窗

| 操作 | 弹窗必须包含 | 完成后的反馈 |
|---|---|---|
| 重命名 | 原名称、新名称 | 原位更新，状态不变，原名保留在调整记录 |
| 排除 / 恢复 | 排除原因（可选）、对点亮进度的影响（如 12 / 178 → 12 / 164） | 显示变化，可撤销 |
| 解散部分分组 | 部分名、包含的章 | 部分层移除，章及其学习数据原位保留，进度不变 |

拆分、合并、移动、手动新增节点在[学习增强](../后续候选/学习增强.md)。

### E. 结构与规划记录抽屉（P1）

按时间列出：结构识别、AI 规划（含理由）、用户编辑。AI 调整可整体"恢复原目录"，恢复前显示将撤销哪些调整。

### F. 空态与异常

- **未识别出目录**："这本书没有可用的标题结构。本期不支持无目录文件的学习；手动创建学习单元在后续版本。" 操作：重新识别 / 返回更换文件。不自动全文拆解；
- **规划结果不理想**：可"恢复原目录"，不影响用户手动编辑；
- **解析失败**：显示原因与重试，不展示空树。

## P04 学习会话 `/studies/:studyId/learn/:nodeId`

### A. 页头

```text
← 返回技能树　第 4 章 / 4.2 上下文工程        [带我学 ▾]　[节点状态与口径]
```

### B. 桌面三框：左原文、中陪学、右笔记

- **左·原文**（定宽 400，可折叠）：本节点原文与引用位置；选中段落后浮出菜单"就这段追问 / 记到笔记"；
- **中·陪学**（弹性，常驻不可折叠）：讲解、对话、测验与输入区；输入区始终可用；
- **右·笔记**（定宽 300，可折叠）：顶部自动带本节点位置（部分 → 章 → 节点），下方单篇 Markdown 编辑器，自动保存并显示"已保存 · 时间"；
- 折叠规则：原文与笔记各自收起为 40px 窄竖条（图标 + 竖排栏名），点击展开；折叠状态按书记忆；宽度重分配恒为"陪学 = 剩余空间"；
- 默认态：≥1280 三框全开；1024–1279 笔记默认收起（用户展开后按书记忆）；<1024 改为"原文 / 陪学 / 笔记"三页签，陪学默认，输入区跨页签固定底部；
- 原文选段"记到笔记"：在笔记光标处插入引用块（`> 节点 · 定位：被引文本`），笔记框收起时自动展开；
- 讲解或测验中的引用点击后原文框自动展开并高亮（见 1.4），折叠不造成引用断链。

### C. 开场

进入节点后首条 AI 消息自动出现：

1. 一句话定位：本节点属于哪部分、推进全书的什么，以及它要解决什么（大纲不可用时可只说后者）；
2. 第一段完整讲解，带 `[1][2]` 引用；
3. 一个简短理解问题或下一步，不一次塞入整章。

首条消息下提供三步引导："读原文 → 问不懂 → 考一组"，可关闭且记住偏好。加载失败保留原文和"重新生成讲解"。

### D. 对话与操作

输入区为多行，Enter 发送、Shift+Enter 换行；生成中可停止。输入区上方固定动作：**考我一组**；节点状态。消息菜单含"复制""就这段追问"。

### E. 内嵌测验

点击"考我一组"后，对话流中先显示测验说明：**题数与通过线**（如"4 题，对 3 题点亮本节点"），再插入测验卡，不另开页面。每组覆盖细节理解与辨析（如判断作者论断）或应用（给定情境怎么用）两类问题。

未作答：题号、题干、选项或简答框、"提交答案"；提交前不显示答案。

已作答：

- 显示对错、正确答案、解释与来源；简答题显示具体评语；
- 错题可"回到原文""再问一个变式"；
- **达到通过线**：显示点亮反馈卡——"● 节点名 已点亮 · 4 题对 4 / 通过线 3"，附一句口径说明与操作"返回技能树""继续学下一个"；
- **未达到**：显示"还差几题"，操作"回到原文""再学一会儿""再考一组新题"；不扣任何东西、不锁任何功能。

重复生成测验时避免同题重复。测验与错题反馈在会话内可回看。

### F. 完成与离开

"节点状态与口径"说明：节点当前状态（未学 / 学习中 / 已点亮）、点亮口径（当前通过，不含长期记忆验证）。用户可直接离开；离开与自由提问不改变状态，已点亮不因离开熄灭。

## P05 设置 `/settings`

分节独立保存：

1. **讲解与测验服务**：地址、模型、密钥；密钥掩码、替换与清除；
2. **资料处理服务**：用于准备原文检索的服务配置；未配置或不可用时，已识别树与原文仍可查看，讲解与测验受限并说明；
3. **用量**：按日期与场景显示请求和用量；
4. **点亮反馈**：音效默认关闭，可开启；粒子与流光动效开关（默认开）；
5. **危险操作**：清除配置与删除数据的入口分开，删除数据需强确认。

保存密钥后只显示掩码；配置失败不清空用户刚填写的其他项。复习偏好与数据导出随后续版本。

## 学习方法抽屉（全站）

右侧抽屉，每张方法卡只有"大白话 + 产品里在哪里 + 一句依据"：

| 方法 | 文案 |
|---|---|
| 先见森林 | 先说出这本书整体讲什么、分几部分怎么推进，再学细节；学任何节点前先知道它在全书里的位置。出现在技能树总述与会话开场。依据《如何阅读一本书》分析阅读。 |
| 先答再看 | 先自己回答，再看反馈；"想起来"比"再看一遍"更能暴露真实掌握。出现在节点测验。 |
| 过关才点亮 | 通过本节点测验才点亮。点亮代表当前通过，不承诺长期记忆。出现在技能树。 |
| 引导你思考 | 先给提示，让你自己走完推理；也可切到直接讲解。出现在"带我学"。 |
| 直接讲给我 | 时间紧或只需理解时，直接给清楚解释，不强行绕弯。出现在"讲给我听"。 |

## 逐页验收走查表

- [ ] 添加一本书不产生空项目；四种格式与失败态都有明确结果；
- [ ] 未配置 AI、AI 失败和超时都能看到并编辑原树；
- [ ] 星盘 / 章内路径 / 工作树三态切换正常，点亮仪式在真实界面触发一次，整章点满触发戴冠；
- [ ] 排除已点亮节点明示进度变化，恢复后还原；
- [ ] 会话首条讲解带引用，引用落在当前书正确位置；
- [ ] 三框折叠与页签切换正常；原文框收起时点引用能自动展开并高亮；笔记自动保存，刷新与离开不丢；"记到笔记"插入的引用块定位正确；
- [ ] 通过线考前可见；未通过再考是新题；通过即点亮并出现在树与书架；
- [ ] 打开会话、只读原文、自由提问都不会点亮；
- [ ] 点亮进度可下钻到测验证据；分母变化有说明；
- [ ] 全程无写死书籍地址、无裸内部编号、无未解释技术术语。
