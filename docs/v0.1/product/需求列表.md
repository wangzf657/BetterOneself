## 1. 验收规则

- **P0**：缺失则"导入→骨架→学→测→点亮"闭环不成立；**P1**：闭环可用但体验明显残缺。
- 完成 = 对应验收逐条通过 + 自动化测试通过 + 真实界面走查通过，不是"端点存在"或"按钮出现"。
- 每条 P0 都含反例；反例与正向结果同等重要。
- LLM 输出质量必须另做真实样书人工抽评，不能由 mock 测试替代。

## B1 一项目一本书

| ID | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| B1-01 | 创建学习项目时同时填写书名并选择一个主文件 | P0 | 用户在一次流程中完成书名与文件选择，完成后进入该书技能树；**反例：不得产生没有主文件却能进入学习的项目。** |
| B1-02 | 主文件仅支持 EPUB、TXT、PDF、Markdown，且每本书一个 | P0 | 四种格式均有明确导入路径；重复添加或拖入多文件时说明限制；**反例：不出现补充资料、粘贴文本、网页或 GitHub 入口。** |
| B1-03 | 导入过程与失败状态清楚 | P1 | 能看到文件解析与目录识别状态；失败显示可读原因与重试，解析失败且无学习数据时可更换文件；离开再回来状态不丢失，进程重启后中断任务可恢复，不能无限转圈。 |

## B2 技能树式知识骨架

| ID | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| B2-01 | 优先利用原书目录与标题快速形成结构树 | P0 | 有可靠目录的样书无需等待 AI 即可看树，节点保留顺序和层级；**反例：结构识别不得调用 LLM，不得因未配置密钥而空白。** |
| B2-02 | 目录识别依据与置信度可见 | P1 | 用户能区分"原书目录""标题规则识别""不确定结构"，低置信内容有提示。 |
| B2-03 | 导入后自动进行一次 AI 拟大纲，失败不阻塞 | P0 | 有可用配置时自动结合章节内容摘要按书的逻辑拟大纲：给出全书总述、跨章部分分组、排除、拆分与合并；章锚点保留、章顺序不变，原目录本身贴合书逻辑时微调或不调整；摘要不可用时退回仅按标题、层级与篇幅规划；调整结果可辨认；原目录先可见，原文引用就绪后才应用结构调整；未配置、失败或超时跳过并保留原树；**反例：不清空树、不删除或合并章锚点、不无限等待，不把全书正文逐字送入单次生成。** |
| B2-04 | 骨架只有结构，不预生成学习内容 | P0 | 树仅含名称、层级、状态与来源，部分层只是分组、总述只是书级说明，均非学习内容；讲解与测验进入学习会话时按节点生成；**反例：导入阶段不得预生成任何讲解、题目或卡片，不得为填充学习内容做全文 LLM 拆解。** |
| B2-05 | 用户可重命名、排除与恢复节点 | P0 | 排除前弹窗预览点亮进度的前后变化（如 12 / 178 → 12 / 164），确认后应用且与预览一致；已排除节点禁止开始新学习、讲解与正式测验，历史会话与测验只读可回看，恢复不产生新证据；**反例：保存编辑后不得静默丢失历史会话与测验记录，已排除节点不得消失而无法恢复，恢复后不得凭空出现新学习记录。** |
| B2-06 | 树展示节点状态且全部学习单元开放 | P0 | 每个学习单元可见未学 / 学习中 / 已点亮状态；任意有效学习单元（无子节点、未排除、有原文引用）可直接开始学习，无顺序解锁门槛；父节点与部分层是容器，只显示聚合进度；**反例：不得出现解锁门槛或按顺序锁死节点，已点亮状态不得随时间自动熄灭；父子均有引用时父节点不得独立点亮；排除全部子节点不得让父节点变成可学习单元。** |

## B3 学习会话

| ID | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| B3-01 | 进入节点学习时 AI 先给出第一段讲解 | P0 | 首段先一句话定位本节点在全书大纲中的位置与推进作用，再基于当前节点讲解，长度适中并带来源，用户可继续问或直接测验；大纲不可用时退回仅基于当前节点；**反例：不得只给空输入框，不得伪造一条用户消息来触发讲解。** |
| B3-02 | 左原文、中陪学、右笔记，引用回跳正确 | P0 | 会话默认三框：原文与笔记可折叠（收起为窄竖条）、陪学常驻；点击讲解或测验中的引用定位到对应原文位置，原文框收起时自动展开并高亮；**反例：打开一个节点不得要求加载整本书全部内容，引用不得落到另一本书，折叠不得造成引用断链。** |
| B3-03 | 学习方法三选一并真正改变陪学方式 | P1 | "带我学 / 讲给我听 / 帮我过关"影响讲解风格与考练密度；书级默认、会话中可切换；任何方法不降低测验通过线。 |
| B3-04 | 自由提问与讲解共存，不改变节点状态 | P1 | 用户可随时提问并得到带引用的回答；提问、阅读与离开都不产生点亮。 |
| B3-05 | 节点笔记随手可记、自动保存 | P1 | 每个节点一篇 Markdown 笔记，输入自动保存、离开与刷新不丢；笔记顶部自动带本节点在大纲中的位置；原文选段可一键插入引用块；**反例：笔记不参与点亮与任何掌握口径，未写笔记不影响节点状态；不提供划线、多条笔记、富文本与导出。** |

## B4 测验与点亮

| ID | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| B4-01 | 按当前学习单元生成有来源的测验 | P0 | 每组 = 3–5 道客观计分题（单选/判断，二元等权）+ 至多 1 道不计分简答练习题，覆盖细节理解与辨析（作者论断是否成立、论据是否支持）或应用（给定情境怎么用）两类问题；题干与解析能回到本节点原文；整组提交后由系统立即判定，提交前不显示答案与解析；简答练习给出具体评语但不计入成绩；同一节点同时最多一组进行中的测验；**反例：不得考当前节点之外的内容，简答练习不得影响是否点亮。** |
| B4-02 | 通过线测验前明示，未通过可再考新题 | P0 | 通过线按计分题数固定映射——3 题对 2、4 题对 3、5 题对 4，在开始测验前可见，由系统按同一映射判定；未通过不点亮，可再学后再考一组**新题**；**反例：重复生成测验不得出现同题；通过线不得中途变化，学习方法、界面与模型输出都不得改变通过线（3/4/5 题临界分与三种学习方法判定结果一致）。** |
| B4-03 | 通过即点亮，口径全站可见 | P0 | 达到通过线后学习单元立即点亮并永久保留，点亮依据为首次通过的测验；已点亮后重考失败显示"原有点亮保留"，不改变点亮时间与首次证据；树、会话与进度处可见口径说明"点亮 = 当前通过，不含长期记忆验证"；**反例：打开会话、阅读行为、自由提问或自评不得点亮；点亮不得被静默取消或因重考失败熄灭。** |
| B4-04 | 测验结果与错题反馈可回看 | P1 | 会话内可回看本节点历次测验：题面、本人作答、逐题正误与简答评语，可一键回到原文对应位置；刷新与重进后逐题内容、作答与评语完全一致。 |

## B5 进度与底线

| ID | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| B5-01 | 全书点亮进度可下钻 | P0 | 进度 = 已点亮有效学习单元 / 有效学习单元（未排除、有原文引用的结构叶），树、会话、书架与星盘使用同一分母；每个数字能下钻到学习单元与首次通过的测验证据；分母为 0 显示"—（无有效学习单元）"；**反例：排除、恢复、解散分组造成分母变化时必须明示，不得静默美化；重命名不得改变分母。** |
| B5-02 | 用户自配密钥且安全保存 | P0 | 密钥输入后可更新、可清除，界面只显示掩码；**反例：日志、页面与 AI 请求上下文不得出现明文密钥。** |
| B5-03 | AI 未配置或失败不阻塞基础路径 | P0 | 树与原文在无 AI 时仍可查看；会话讲解或测验失败时显示可读原因与重试，原文不失效；**反例：不得整页空白或无限等待。** |
| B5-04 | 服务配置与用量可见 | P1 | 设置页可配置讲解测验与资料处理服务；按日期和场景查看 AI 用量；空数据有明确反馈。 |

## 2. 实施顺序（不是功能范围扩张）

1. **骨架可信**：B1、B2。用真实样书证明目录、规划降级与树编辑，未通过不堆页面。
2. **学测点亮闭环**：B3、B4。打通会话、测验、点亮与树上反馈。
3. **进度与收口**：B5 与各 P1，逐页真实走查。

每个阶段跑全量后端测试与主链路 E2E；E2E 至少覆盖：添加 → 树 → 学 → 测 → 点亮 → 进入下一节点；AI 规划失败保留原树；排除已点亮节点明示影响；引用回跳落在当前书正确位置；未通过再考不重复同题；点亮后重考失败不改变点亮；刷新后测验作答与逐题判分完整一致。
