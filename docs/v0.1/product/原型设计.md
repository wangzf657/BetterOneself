# V0.1 原型设计

> 日期：2026-11-20｜形式：桌面 Web 高保真文字线框与交互脚本，范围收缩后
> 配套：[页面清单](页面清单.md)；页面与状态定义以页面清单为准。
> 样例书名仅为说明信息密度，不代表目录规划结果已验证。

## 1. 视觉方向

### 1.1 设计关键词

**章节星盘、路径点亮、克制而华丽的仪式。**

- 星盘是舞台：进度仪式与导航交给游戏化视图（星盘 + 章内路径），可以尽情华丽；
- 工作归工作：搜索、排除、重命名等操作职责在工作树视图，不向游戏感妥协；
- 每屏只有一个视觉主动作；
- 点亮是全站唯一的高亮仪式：粒子迸发 → 连线流光 → 金色实心；动效一次性完成，不常驻；
- 整章点亮戴金冠，是比单点点亮更高一档的仪式；
- 进度数字重要，口径与下一步同等重要；
- 红色只用于测验未通过与破坏性操作。

### 1.2 桌面基准

- 设计基准 1440 × 900；最小桌面宽度 1024；
- 顶栏高 56，页面左右留白 32；
- 普通页面内容最大宽度 1080；技能树与会话工作区最大宽度 1440；
- 卡片圆角 10、边框 1；间距以 8 为基数；
- 正文 14/22，页面标题 24/32，大进度数字 40/48；
- 树节点行高 36，按钮标准高 36；
- 弹窗宽度：普通表单 520，结构与规划记录抽屉 480。

### 1.3 状态色

| 状态 | 颜色倾向 | 使用方式 |
|---|---|---|
| 未学 | 中性灰 | 空心圆 ○，不整块铺灰 |
| 学习中 | 蓝 | 半亮 ◐ 与呼吸微光 |
| 已点亮 | 暖金 | 实心 ●；"金"只用于点亮语义 |
| 路径流光 | 金 | 已走过路径的连线点亮，与点亮同色系 |
| 章冠 | 金 | 整章点亮后章星戴冠，全站唯一的更高仪式 |
| 待确认 | 琥珀 | 节点左侧小点与说明 |
| AI 调整 | 紫 | 仅调整标记与记录，不用于主按钮 |
| 已排除 | 灰 + 删除线 | 保留在星盘与树中，可恢复 |

颜色必须配合文字或图标，不能只靠颜色传达状态。

## 4. 原型 C：技能树（核心屏）

技能树有两个视图：**章节星盘 + 章内路径**（默认，负责进度仪式与导航）和**工作树**（缩进树，负责搜索、排除、重命名等全部整理操作）。工具栏右侧切换器固定为「星盘 | 工作树」，选择按书记忆；两个视图共享右侧详情面板。

### 4.4 点亮仪式（动效脚本）

```text
测验达标瞬间（会话内反馈 → 返回路径 / 星盘时同步呈现）：
  1. 节点迸发一次金色粒子（约 0.6s，一次即止）；
  2. 该节点到已走路径的连线流光点亮；
  3. 节点变金色实心 ●，轻缩放一次；
  4. 整章点满：章星星环填满动画 → 戴金冠，星盘给一次更大的粒子仪式。

常驻动效只有两种：学习中节点 / 当前章的呼吸微光；已走路径的低速流光。
音效默认关闭，设置页可开；所有动效一次性完成，不得拖慢滚动与视图切换。
```

### 4.5 排除确认弹窗（工作树与详情面板通用）

## 6. 核心点击流

### 6.1 首次点亮闭环

```text
我的书
  → 添加一本书
  → 查看技能树（星盘）
  → 点第 1 章 → 章内路径
  → 开始学习 1.1
  → 读原文 + 首段讲解
  → 提一个问题
  → 考一组（4 题对 3）
  → 通过 → 点亮仪式（粒子 → 流光 → 金实心）
  → 返回星盘，第 1 章星环 1 / 8
```

### 6.2 未通过再考

```text
考一组
  → 未通过（2 / 4）
  → 回到原文再学
  → 再考一组新题
  → 通过 → 点亮
```

### 6.3 AI 失败降级

```text
添加一本书
  → 基础目录已显示
  → 规划失败提示
  → 星盘照常可用
  → 切工作树手动排除"本章小结"
  → 正常学习与测验
  → 稍后重试规划
```

## 7. 响应式与可访问性

- 1024 以下技能树右详情收窄为覆盖抽屉；
- 1024 以下会话三框改为"原文 / 陪学 / 笔记"三页签，陪学默认，输入区跨页签固定；768 以下顶部导航折叠为菜单，主操作固定在底部安全区；
- 章内路径在窄屏为单列纵向滚动；
- 星盘、路径节点、树节点、测验选项、按钮支持键盘焦点；弹窗打开后焦点进入第一个输入项；
- 所有动效支持系统"减少动态效果"设置：粒子与流光退化为一次状态变化；
- 长书名、长节点名最多两行，完整名称悬停或聚焦可见；
- 加载、失败、空态和禁用都不仅靠颜色区分。

## 8. 原型评审重点

1. 星盘与路径是否一眼回答"学到哪了、下一个学什么"？
2. 工作树是否能无损失完成全部整理操作（搜索、排除、重命名）？
3. 点亮仪式是否华丽但可信：有口径、可下钻、不被行为伪造？
4. 会话是否始终原文在手、来源可回？
5. 通过线是否考前可知、失败是否无惩罚？
6. AI 不可用时，是否仍有一条完整、诚实的基础路径？
