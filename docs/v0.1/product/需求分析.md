# V0.1 产品需求分析

> 日期：2026-11-20｜状态：现行产品事实源，范围已收缩为最薄闭环
> 配套：[需求列表](需求列表.md)｜[页面清单](页面清单.md)｜[原型设计](原型设计.md)
> 边界：本文只讨论用户、问题、学习逻辑与产品取舍，不规定表、字段、接口或解析库。

## 1. 一句话定位

**导入一本书 → 看到技能树式的知识骨架 → 点节点进入「左原文、中陪学、右笔记」的学习 → 通过本节点测验点亮节点。**

V0.1 是单机、单用户、自导入的验证版本，只验证一条最薄闭环：**「学习—考练—点亮」能否驱动一个人把一本书一章一章学下去**。复习、计划、强度分级、掌握档案等全部在[后续候选](../后续候选/)，不进本版。

## 2. 为什么收缩到最薄闭环

前身实验的失败不是功能不够，而是一次铺开 40 条需求，把"功能存在"当成"闭环成立"（证据见[注意事项](../注意事项.md)）。为避免重演，本版只回答三个问题：

- 导入后，能否立刻看到一棵可信、可走动的树？
- 学一个节点，是否原文在手、能问、能考？
- 测验通过点亮后，用户是否想点下一盏灯？

## 3. 目标用户与场景

### 3.1 目标用户

有明确教材、想真正学完一本书，但缺少过程管理的成人自学者。首批以技术学习者为主：目录清楚、概念与操作并重，便于验证"讲解—考练—点亮"闭环。

典型状态：书下载了却停在"读过前几章"；看讲解觉得懂，合上书讲不出来；不知道学到哪了，也不知道下一步学什么。

### 3.2 日常使用

| 场景 | 用户可用时间 | 产品应提供的主路径 |
|---|---:|---|
| 专注学习 | 20–60 分钟 | 打开书 → 技能树挑一个未点亮节点 → 原文 + 讲解 + 提问 + 随手记笔记 → 测验通过点亮 → 知道下次从哪继续 |

碎片复习场景随复习体系一起放在后续版本。

### 3.3 不服务的情况

- 没有书、只想随意聊天的人；
- 只想标注和记录阅读进度、不需要考练的人；
- 需要班级、账号、社区或多人协作的人。

## 4. 核心问题与产品回答

| 用户问题 | V0.1 的回答 | 明确不采用 |
|---|---|---|
| 导入后"然后呢" | 第一屏就是技能树骨架与点亮进度 | 空聊天框；一排功能入口 |
| 这棵树可信吗 | 原书结构零 LLM 先出树；AI 只做一次拟大纲（总述、部分分组、排除/拆分/合并），章锚点保留，失败保留原树 | 把机器结果包装成绝对正确 |
| 现在学什么 | 树上挑一个未点亮节点，或"继续上次" | 统计图表首页 |
| 学完凭什么说会 | 本节点测验通过即点亮，通过线测验前明示 | 阅读时长、打开次数、自评 |
| 点亮等于学会吗 | 不等于。点亮 = 当前通过，不含长期记忆验证；复习体系在后续版本接入后再升级点亮语义 | 把点亮包装成"学透" |
| 测验没过怎么办 | 再学一会儿、再考一组新题；树不惩罚、不锁进度 | 关卡锁死、惩罚性体验 |

## 5. 产品范围

### 5.1 本版必须做通

1. 一个学习项目只绑定一本书、一个主文件（EPUB / TXT / PDF / Markdown）；
2. 导入后形成可修正的结构树；树只有结构信息，不预生成讲解、题目等细节；
3. 树节点状态可见：未学 / 学习中 / 已点亮；全部节点开放，无解锁门槛；
4. 学习会话：左原文、中陪学、右笔记三框（两侧可折叠、陪学常驻）；可自由提问；可选学习方法；节点笔记自动保存；
5. 本节点测验：有来源、提交前不泄露答案、通过线明示；通过即点亮；
6. 全书点亮进度可下钻到节点与测验证据；
7. 密钥安全与 AI 失败降级。

### 5.2 本版明确不做（移入[后续候选](../后续候选/)）

- 目标访谈、分日计划、逾期重排、督促、摘要与周复盘 → [计划与督促](../后续候选/计划与督促.md)
- 卡片、FSRS 复习、薄弱点、Anki 导出 → [复习与卡片](../后续候选/复习与卡片.md)
- 章强度三档、掌握档案、自评、高风险回退、结业报告 → [掌握档案与强度分级](../后续候选/掌握档案与强度分级.md)
- 前测、按掌握度切讲解、会话进度条、整本阅读页、手动拆分合并 → [学习增强](../后续候选/学习增强.md)
- 全量数据导出与学习报告下载 → [数据与导出](../后续候选/数据与导出.md)
- 书籍分享、社区、账号、跨书统一档案（维持原否决）。

## 6. 产品概念

| 概念 | 产品含义 | 关键约束 |
|---|---|---|
| 书 / 学习项目 | 一次"学这本书"的完整容器 | 一本书对应一套骨架、会话、测验与点亮 |
| 目录节点 | 从原书结构识别出的层级 | 展示识别可信度；可重命名、排除 |
| 大纲总述与部分层 | AI 拟大纲的产物：一句话总述 + 按书的逻辑分的部分 | 只是分组：章锚点保留、章顺序不变；可重命名、排除与解散；目录已贴合书逻辑时可无 |
| 骨架节点（知识点） | 一次学习、测验和点亮的基本单位 | 不等于正文切片；须有来源；可排除 |
| 技能树 | 骨架的全书视图与进度视图 | 状态图，不是关卡；全部节点开放 |
| 学习方法 | 带我学 / 讲给我听 / 帮我过关 | 软偏好，不降低通过线 |
| 学习会话 | 围绕一个节点的讲解与提问 | 带当前节点上下文与来源 |
| 节点笔记 | 挂在骨架节点上的单篇个人笔记 | 位置骨架自动、内容手写（结构笔记+概念笔记）；自动保存；不参与点亮与统计 |
| 测验 | 按当前节点生成的一组有来源的题 | 提交前不泄露答案；通过线明示 |
| 点亮 | 节点测验通过后的状态 | 当前通过证据；不承诺长期记忆；永久保留 |

**骨架节点（知识点）仍是产品枢纽**：会话讲它，测验考它，点亮证明它。后续的卡片与档案也挂它，任何新功能不得绕过它另建一套进度。

## 7. 核心闭环

```text
导入一本书
  → 识别目录（零 LLM），导入即可见原树
  → 自动一次 AI 拟大纲：全书总述 + 部分分组 + 排除/拆分/合并（失败则保留原树）
  → 技能树：确认调整、排除不学的部分
  → 点一个节点进入学习会话
  → 原文 + 讲解 + 提问
  → 本节点测验
  → 达到通过线 → 节点点亮
  → 树上进度更新 → 继续下一个节点
```

## 8. 关键产品逻辑

### 8.1 骨架先于细节

结构识别零 LLM，导入即可见原树；AI 规划升级为**拟大纲**（依据《如何阅读一本书》分析阅读）：在章节内容摘要基础上理解书的逻辑，产出全书总述、部分分组与排除、拆分、合并——原书目录本身贴合书的逻辑时（多数技术书），微调甚至不调整。拟大纲仍是结构信息，不生成学习内容；摘要不可用时退回仅按标题、层级与篇幅，正文逐字内容不进入规划上下文。讲解与测验在进入学习时才按节点生成，**导入阶段不预生成任何学习内容**——这是前身实验入口慢贵的直接反面。

### 8.2 点亮口径必须诚实

- 点亮 = 该节点一次测验达到通过线，是**当前通过**的证据；
- 点亮不代表长期记忆；复习体系（后续版本）接入后，再定义巩固与风险语义，届时升级点亮口径；
- 点亮永久保留，不因时间流逝自动熄灭；重命名不改变点亮状态；
- 排除已点亮节点必须明示对进度的影响，不静默变化；
- 全书点亮进度 = 已点亮有效节点 / 有效节点（未排除节点）；无可统计对象显示"—"；
- 每盏灯都能下钻到测验证据。

### 8.3 测验通过线明确且不可绕过

每组 3–5 题、以客观题为主，通过线在测验开始前明示；未通过可再学、再考一组**新题**，避免同题重复；"帮我过关"等方法不降低通过线；打开会话、只读原文或自由提问都不产生点亮。

### 8.4 学习方法只改变陪学方式

带我学 = 先引导思考再讲解；讲给我听 = 直接给清楚解释；帮我过关 = 高密度考练。书级默认、会话内可切换；任何方法都不越过通过线。

### 8.5 四问贯穿讲解与测验

艾德勒四问（整体讲什么 / 细节怎么说 / 说得对吗 / 对我有什么用）是讲解与测验的内容骨架，不新增页面或流程：全书总述回答"整体讲什么"；会话开场定位"本细节在全书哪个位置、推进什么"（B3-01）；测验在细节理解之外覆盖辨析与应用（B4-01）。

## 9. 用户旅程

### 9.1 第一次使用

1. "添加一本书"：填书名、选文件；
2. 看到解析进度，基础目录可用即进入技能树；
3. 确认 AI 调整、排除不学的部分（如习题答案）；
4. 点第一个节点 → 左原文、中讲解、右笔记 → 提问 → 考一组 → 通过 → 看到第一盏灯亮起。

### 9.2 日常学习

打开书 → 看点亮进度 → 继续上次或挑下一个未点亮节点 → 学、问、考 → 点亮 → 离开时知道下次从哪继续。

## 10. 产品原则

按优先级排序，冲突时上位优先：

1. **闭环大于单点**：导入、树、学、测、点亮彼此衔接，缺一不可。
2. **先结构，后智能**：没有 AI 也能看见树；AI 用于改善结构，不阻塞学习。
3. **通过证据大于阅读行为**：读过、看过、问过都不等于通过。
4. **点亮口径诚实**：不把"当前通过"包装成"学透"。
5. **用户确认大于 Agent 自作主张**：AI 调整可见可改，删除有确认。
6. **信任锚定原书**：讲解、题目、测验反馈都能回到来源。
7. **不惩罚**：未通过不扣分、不锁节点、不羞辱。
8. **成本随学习量，不随藏书量**：导入只做结构，不做内容预生成。

## 11. 验证标准与止损线

### 11.1 本版成功证据

| 要验证的问题 | 证据 |
|---|---|
| 导入入口是否成立 | 一本真实 300 页左右的书能快速看到结构树；结构识别不消耗 LLM；AI 失败时树仍在 |
| 骨架是否适合学习 | 样书人工抽评：每个节点能承载完整讲解与一组有区分度的题 |
| 闭环是否有驱动力 | 自己用真实书连续学习若干天、点亮若干节点后，仍愿意打开下一次 |
| 点亮是否可信 | 每盏灯可下钻到测验证据；通过线从未被静默调整 |

### 11.2 止损线

出现以下任一情况，停止扩展功能：

- 必须等待全文 LLM 拆解才能看到树；
- 导入阶段预生成讲解或题目，入口重新变慢变贵；
- 通过线可被任何方式绕过或静默放水；
- 打开会话、阅读行为或自评能产生点亮；
- 测试通过，但真实界面的进入、回跳、重考仍失败。
