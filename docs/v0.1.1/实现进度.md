## 二、后端（B6-07 收尾轮新增/修正）

- `app/services/assets.py`：**修复 EPUB 内容文档错解码**——`_decode_doc` 按 BOM / XML 声明 / UTF-8 三级解码后再交给解析器（libxml2 不认 `<meta charset>`，无 XML 声明的 UTF-8 文档曾被读成 Latin-1 乱码；`tests/test_assets.py::test_sanitize_decodes_content_doc_encodings` 回归锚点）。
- `app/ingest/chunker.py`：**修复 location 存成 span 元组**——`_chunks_from_paragraphs` 的 flush 曾把 `(start, end)` 元组整体写入 `line_start/line_end`（PDF 无书签降级的 `page_start/page_end` 同样中招），V0.1 起即存在，前端此前无标量消费方未暴露；B6-07 定位是第一个真消费者。现存标量，`tests/test_ingest.py` 补类型断言。**注意：修复前导入的旧书，行号/页码字段是数组，需重新解析才能用原文定位。**
- `app/main.py`：SPA 响应头——入口页与非常规资产 `Cache-Control: no-cache`（升级后用户立刻拿到新版本），`/assets/*` 哈希文件名 immutable（`_ImmutableAssets` 挂载）；`tests/test_assets.py::test_spa_cache_headers`。版本号改 0.1.1。
- `tests/test_launcher.py`、`scripts/build_exe.py`、`betteroneself.spec` 不变（nh3 随 app.services.assets 自动进包；alembic 0002 在 datas）。

## 三、前端（B6-07 本轮全量落地）

| 文件 | 内容 |
|---|---|
| `src/features/learn/OriginalView.tsx`（新） | 四格式原文视图。PDF：pdf.js 动态加载（worker 用 `?url` 导入——build 下 `new URL(<裸包名>)` 不被 Vite 解析）、IntersectionObserver 懒渲染；跳页定位用**常量布局算术**（sticky 条高 + 内边距 + (n-1)×(页高+间距)），页高以「页面容器实测宽」估一次、再由第 1 页真实渲染高度回填校正；跳页被视口钳制（尾页内容不足一屏）时「当前页」仍按目标页计（阅读器惯例）并抑制程序滚动的回声重算；用户滚轮/按键/触摸即接管。TXT：规范化文本按 `data-line` 渲染、二分找顶边行反向定位；MD：react-markdown + remark-gfm，外链图可见、本地相对路径图占位注明单文件导入不支持；EPUB：取 `/assets/{href}` 消毒片段渲染，首段文本匹配细化到段落、退到标题锚点；四格式都在前向定位后立即回报位置（短文不产生滚动事件）。 |
| `src/features/learn/SourcePane.tsx` | 顶部「解析文本 / 原文」toggle（`bookPref(studyId,"srcView")` 按书记忆，无原文位置时禁用并收敛回解析文本）；切回解析文本时滚到原文回报的切片并高亮（匹配不到回上次定位）；解析文本分支行为与 V0.1 完全一致。 |
| `src/index.css` | `.prose-book` 原文排版（标题/列表/引用/表格/图片/图注）。 |

**本轮顺带修复的存量前端缺陷（E2E 揪出）**

1. **工作树/书菜单弹窗残留模态层**：重命名/排除/删除弹窗嵌在 `DropdownMenuContent` 里 + `onSelect` 里 `preventDefault()` 保持菜单开着，弹窗关闭后整页残留 `aria-hidden` + `pointer-events:none`，所有 `getByRole` 失明（planning-fail 超时的病根）。已把弹窗提升为菜单的兄弟节点、菜单先卸载再开弹窗（`WorkTreeView.tsx` 重构 NodeMenu/RenameNodeDialog/ExcludeNodeDialog；`TreePage.tsx` 书菜单同改）。
2. **ProposalDialog 缓存不刷新**：`enabled` 翻转不触发 refetch，「确认前在原树学习」后打开确认页看到的是打开前的旧预标注。已改为每次打开重取 + flagged 变化时把新冲突条目从已选中剔除（`ProposalDialog.tsx`）。
3. **DetailPanel 浮层遮挡交互**：详情卡原为 `fixed` 浮层，会盖住双进度区按钮或工作树行菜单（先点一下只能关卡片）。已改为**停靠在主工作区右列**（`TreePage.tsx` flex 布局承载宽度），不再遮挡任何交互元素。
