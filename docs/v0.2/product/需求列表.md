# V0.2 产品需求列表

> 日期：2026-11-20｜状态：现行产品验收清单
> 上游：[需求分析](需求分析.md)｜交互定义：[页面清单](页面清单.md)、[原型设计](原型设计.md)
> 技术文档只通过本文需求 ID 映射实现，不在本文规定字段、接口或库。

## 1. 验收规则

- **P0**：缺失则“学透一本书”不成立；**P1**：闭环可用但体验明显残缺；**P2**：收尾增强。
- 完成 = 对应验收逐条通过 + 自动化测试通过 + 真实界面走查通过，不是“端点存在”或“按钮出现”。
- 每条 P0 都含反例；反例与正向结果同等重要。
- LLM 输出质量必须另做真实样书人工抽评，不能由 mock 测试替代。
- 本清单共 40 条，未沿用 V0.1 的完成状态。

## B1 一项目一本书

| ID | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| B1-01 | 创建学习项目时同时选择一本书和一个主文件 | P0 | 用户在一次流程中填写名称、目标并选文件，完成后进入该书；**反例：不得产生没有主文件却能进入计划与学习的新项目。** |
| B1-02 | 主文件只支持 EPUB、TXT、PDF、Markdown，且每本书仅一个 | P0 | 四种格式均有明确导入路径；重复添加或拖入多文件时说明限制；**反例：不出现补充资料、粘贴文本、网页或 GitHub 入口。** |
| B1-03 | 导入过程与失败状态清楚 | P1 | 能看到文件解析、目录识别和后续准备状态；失败显示可读原因与重试；离开再回来状态不丢失，不能无限转圈。 |
| B1-04 | 旧项目数据可继续查看和学习 | P1 | 旧项目不丢资料、卡片、计划与档案，并明确标为旧版项目；不适用的新进度如实显示“不适用”，不伪造 0% 或 100%。 |

## B2 可信、可编辑的知识骨架

| ID | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| B2-01 | 优先利用原书目录与标题快速形成结构树 | P0 | 有可靠目录的样书无需等待全文 AI 拆解即可看树，节点保留顺序和层级；**反例：结构识别不得调用 LLM，不得因未配置 AI 密钥而空白。** |
| B2-02 | 目录识别依据与置信度可见 | P1 | 用户能区分“原书目录”“标题规则识别”“不确定结构”，低置信内容有提示；不能把推断结果显示成原书事实。 |
| B2-03 | 导入后自动进行一次 AI 目录规划 | P0 | 有可用配置时自动分析标题、层级和篇幅，给出排除、拆分、合并与章内学习区域调整，调整结果可辨认；原目录先可见，原文引用就绪后才应用结构调整；**反例：不读取全书正文重新生成目录，不在用户点击页面时重复触发，不在引用未就绪时制造出无法回源的学习单元。** |
| B2-04 | AI 未配置、失败或超时均不阻塞基础结构 | P0 | 自动跳过或结束规划，保留原结构并给出“可稍后重试”；**反例：不得清空树、无限等待或强迫用户配置 AI 后才能学习。** |
| B2-05 | 用户可修正目录与知识点 | P0 | 支持重命名、新增、拆分、合并、移动、删除，以及把前言、致谢、纯答案等排除出学习范围；影响既有学习数据时先说明；**反例：保存编辑后不得静默丢失卡片、测验或掌握证据。** |
| B2-06 | 知识点粒度适合学习、考练和掌握追踪 | P0 | 样书评审中，每个有效知识点都能说明学习目标、回到足够原文并形成合理任务；非学习单元与无来源节点不进入学透统计；**反例：不得按正文切片机械建点，也不得无标题时自动回落到全文 LLM 拆解。** |

## B3 强度与计划

| ID | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| B3-01 | 每章可设置略读、读透或学透 | P0 | 目录与计划中均能看见并调整强度，任务形态随强度变化；**反例：略读章不得生成知识点测验，读透章不得要求逐点测验，改强度不得篡改历史证据。** |
| B3-02 | 目标访谈收集目标、期限和每日可用时间 | P1 | 三问可跳过并使用明示默认值；可批量设置章强度；默认值与由此产生的计划都可修改。 |
| B3-03 | 生成可确认、可调整的分日计划 | P0 | 计划遵循目录顺序、强度、每日时长和期限，超出期限时明确说明；用户确认后才成为今日任务，可增删任务和改期；**反例：不得未经确认改生效计划，不得只有改期而无法增删。** |
| B3-04 | “我已掌握”与系统评估分开 | P1 | 计划任务与档案中，尚未自评的学透章有效知识点提供“我已掌握”；点击后先完成一道不泄露答案的快速验证，通过才记录自评并减少后续新任务；未通过不修改自评、补回生效计划并给出任务入口，出题失败或中途退出不改变自评与计划；略读与读透章不提供此捷径，系统档案不把自评本身当作通过证据。 |

## B4 学习会话

| ID | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| B4-01 | 进入知识点学习时 AI 先给出第一段讲解 | P0 | 首段内容基于当前知识点、长度适中并带来源，用户可继续问或直接测验；**反例：不再只给空输入框，不伪造一条用户消息来触发讲解。** |
| B4-02 | 原文、讲解、提问与引用回跳在同一学习上下文 | P0 | 用户可查看本知识点原文，点击引用定位到对应原书位置；自由提问不改变计划；**反例：打开一个知识点不得要求下载或加载整本书的全部内容。** |
| B4-03 | 学习方案用大白话呈现并真正改变陪学方式 | P1 | “带我学 / 讲给我听 / 帮我过关”影响讲解与考练密度，书级默认、章级可覆盖、会话中可切换；任何方案都不越过章强度。 |
| B4-04 | 支持费曼复述与至少一次追问 | P1 | 用户用自己的话讲解，AI 指出缺漏并追问，读透章以此判定是否过关；结果与证据可回看。 |

## B5 测验与卡片创建

| ID | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| B5-01 | 学习过程中可生成并回答有来源的测验 | P0 | 客观题即时判定，简答题给出评价与改进建议；答错能回看原书对应内容并更新掌握证据；**反例：未作答前不得泄露答案，略读与读透章不得生成违反强度的测验任务。** |
| B5-02 | 答错自动形成一张可复习卡片 | P0 | 卡片包含清晰问题、答案、关联知识点和来源，随后进入复习队列；**反例：不得重复生成同题卡，不得只在界面提示而实际未入队。** |
| B5-03 | 支持对话卡壳标记与手建卡片，禁止批量自动制卡 | P1 | 用户可从对话保存卡片，也可在卡片页选知识点并填写正反面；所有卡片可辨认来源；不存在“学完自动建议一批卡片”的入口。 |

## B6 复习与薄弱点

| ID | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| B6-01 | 首页与复习页展示到期卡片 | P0 | 到期即出队，每日上限可调整，可按书筛选；无卡时如实说明；**反例：未到期卡不得冒充今日任务，多本书不得无标识混算。** |
| B6-02 | 四档评分改变下次复习时间 | P0 | 忘了、困难、良好、轻松均可鼠标与键盘操作，评分后显示下次时间；“忘了”当天再次重现；**反例：评分不能只改界面而不影响队列。** |
| B6-03 | 卡片可筛选、编辑、暂停、删除和导出 | P1 | 可按书、知识点、状态筛选；编辑不改写历史评分；导出得到真实文件；高级复习参数可查看且有解释。 |
| B6-04 | 连续错误形成薄弱点并反哺后续学习 | P0 | 薄弱点带具体错误证据，后续出现针对性任务，补救后有清楚变化；**反例：不得只显示红色标签而不影响任务，不得删除原始错误证据。** |

## B7 督促与重排

| ID | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| B7-01 | 首页直接回答“今天该做什么” | P0 | 展示今日任务、到期复习、继续上次和当前书进度，任务可直接进入会话；**反例：不得退化成只有统计图表的仪表盘。** |
| B7-02 | 逾期任务自动重排，长期中断可回炉 | P0 | 只搬未完成逾期任务，显示知识点名与日期变化；长期中断需用户确认后重排并优先处理高风险卡；**反例：不堆积逾期任务，不重复复制任务，不显示内部编号代替名称。** |
| B7-03 | 每日摘要与周复盘服务于下一步 | P2 | 有学习行为才生成摘要；周复盘给完成、掌握与遗忘情况及建议，建议经确认才调整计划；无数据时如实说明。 |

## B8 全书进度与掌握档案

| ID | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| B8-01 | 首页与书页展示全书学透百分比和章级进度 | P0 | 分母是学透章内有效知识点，分子是其中有通过证据且关联卡片无高风险的“有效通过”知识点；可同时看到学透章数与阅读进度，分母为 0 显示“—”；**反例：改强度、排除或合并造成分母变化时必须明示，不得静默美化百分比。** |
| B8-02 | 章完成由对应强度的证据决定，且可回退 | P0 | 略读看显式读完，读透看复述通过，学透看全部有效知识点有效通过；高风险出现后，关联知识点退出全书分子且所属章不再完成；**反例：不得出现学透章因高风险未完成而全书仍为 100%，任务勾选、阅读时长或自评也不得直接判定学透。** |
| B8-03 | 掌握档案按目录树展示证据与自评 | P1 | 保留父子层级，可筛选状态；每个状态能下钻到测验、复习或复述证据，自评与系统评估并列而不混淆。 |
| B8-04 | 达到结业条件后生成可导出的学习报告 | P2 | 报告含各章进展、证据与薄弱点变化；首次达成即可下载，进度回退后再次达成不重复制造多份报告。 |

## B9 信息架构与学习方法

| ID | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| B9-01 | 学习是首页，准备动作收纳在书页 | P0 | 顶栏为学习、我的书、复习、卡片、档案、设置；书页集中目录、原文与计划；**反例：不得把导入、目录和计划分散为彼此找不到的独立一级页面。** |
| B9-02 | 复习、卡片和档案可一级直达，并始终有书上下文 | P1 | 默认使用最近学习的书，可切换；切换后列表、统计和操作对象一致，不把多本书混成一个统一档案。 |
| B9-03 | 学习方法用用户听得懂的语言解释 | P2 | 全站问号入口说明先答再看、快忘时复习、你讲我挑错、过关才前进等方法；不出现未解释的“苏格拉底”“FSRS”“向量”等裸术语。 |

## B10 安全、导出与已知断点

| ID | 需求 | 优先级 | 验收标准 |
|---|---|---|---|
| B10-01 | 用户自配密钥且安全保存 | P0 | 密钥输入后可更新、可清除，界面只显示掩码；**反例：日志、页面、导出文件和 AI 请求上下文不得出现明文密钥。** |
| B10-02 | Anki 与学习报告导出必须真实下载 | P0 | 浏览器获得内容与文件名正确的文件，重新打开可核对内容；**反例：不得拦截默认下载后只弹成功提示。** |
| B10-03 | 所有来源回跳保留正确书籍上下文 | P0 | 从目录、会话、错题、复习和卡片进入原文，都落在当前书与正确位置；**反例：不得使用写死的项目地址或回到另一本书。** |
| B10-04 | 修复筛选与展示中的已知假功能 | P1 | 卡片可按包括叶子在内的知识点筛选，逾期提示显示名称，掌握档案不再扁平化，复习按书筛选有效；结果与空态均需验证。 |
| B10-05 | 全量数据与 AI 用量可查看、可带走 | P1 | 可导出完整学习数据，设置页按日期和场景查看用量；导出内容不含明文密钥，空数据与大数据量均有明确反馈。 |

## 2. 实施顺序（不是功能范围扩张）

1. **骨架可信**：B1、B2。先用真实样书证明目录、规划、编辑与粒度，未通过不继续堆页面。
2. **学习闭环**：B3–B8。打通计划、学习、测验、卡片、复习、督促和证据进度。
3. **体验收口**：B9、B10 与各组 P1/P2。逐页真实走查，清零已知假功能。

每个阶段均需跑全量后端测试和主链路 E2E；E2E 至少覆盖：真实下载、目录规划失败保留原树、编辑不丢证据、答错成卡、次日复习、进度回退。

## 3. 与旧版的关系

V0.1 的代码与测试可作为实现起点，但旧需求完成状态全部清零。是否复用某个模块，由它能否满足本文验收决定；不得因为“旧版已经有”而跳过真实结果验证。
