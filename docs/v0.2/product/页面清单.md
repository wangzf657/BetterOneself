# V0.2 页面清单

> 日期：2026-11-20｜状态：高还原产品交互规格
> 上游：[需求分析](需求分析.md)、[需求列表](需求列表.md)｜视觉线框：[原型设计](原型设计.md)
> 本文描述页面、内容、状态与操作，不规定接口、字段或技术组件。页面路由用于定位，不代表实现已经完成。

## 1. 信息架构与全局约定

### 1.1 一级导航

桌面端顶部固定导航，顺序不可变：

```text
BetterOneself｜学习　我的书　复习　卡片　档案　　　　　　　　学习方法 ?　设置
```

- **学习** `/`：今天该做什么，不是数据统计首页。
- **我的书** `/studies`：所有学习项目与“添加一本书”。
- **复习** `/review`：到期卡片。
- **卡片** `/cards`：所有卡片的按书管理。
- **档案** `/mastery`：按书查看掌握证据与全书进度。
- **设置** `/settings`：服务、复习、数据与用量。
- **学习方法**：全站问号按钮，打开说明抽屉，不改变当前页面状态。

当前导航有明确选中态。复习导航可带今日到期数量，但不使用红色制造焦虑。

### 1.3 全局书选择器

复习、卡片、档案、摘要页标题旁均有书选择器：

- 默认选“最近学习的书”，选项按最近学习排序；
- 显示书名，不只显示项目名或内部编号；
- 切换后，页面统计、列表、空态和全部操作一起切换；
- 不使用“全部书”混合复习或掌握数据；本版没有跨书统一档案；
- 仅一本书时不显示成复杂下拉，只显示可点击书名。

### 1.4 全局反馈

| 状态 | 表现 |
|---|---|
| 页面加载 | 保留页面骨架，不白屏；加载超过 8 秒显示“仍在处理，可稍后刷新” |
| 局部保存 | 按钮进入“保存中…”，禁止重复提交；成功后原位更新，不强制跳页 |
| 成功 | 轻量提示说清结果，例如“已形成 1 张复习卡”，不用“操作成功” |
| 可恢复失败 | 原位显示原因与“重试”，保留用户已填写内容 |
| 无权限配置 | 说明缺少哪项配置，但不把用户强行带离当前学习路径 |
| 删除 | 弹窗列出会受影响的任务、卡片、测验和证据；输入书名仅用于删除整本书 |
| 离线 / 服务断开 | 顶部持续条提示，已显示内容仍可阅读，恢复后可重试 |

所有 toast 都不能替代页面内的真实状态。下载、成卡、保存等结果必须能在对应页面再次核实。

### 1.5 引用与原文定位

统一引用样式为带序号的小角标，如 `[1]`。点击后：

1. 若在学习会话，左侧原文滚动到对应段落并高亮；
2. 若在其他页面，打开原书阅读页并保留当前书；
3. 若原位置不可用，显示“来源位置已变化”，同时给出所在章与来源文本，不跳到空白页；
4. 返回时回到原页面、原滚动位置与原筛选。

### 1.6 通用空态原则

每个空态都回答三件事：**为什么为空、现在能做什么、做了以后会得到什么**。禁止只写“暂无数据”。

## P01 添加一本书 `/studies/new`

### 页面目标

让用户在一次流程里完成“目标 + 文件”，并理解接下来会看到什么，而不是先建空项目再找上传入口。

### 布局

页面最大宽度 760，居中。顶部为“← 返回我的书”，标题“添加一本书”，副标题“先从一本书开始，目录、计划、卡片和复习都会归属于它”。

表单按顺序：

1. **书名 / 学习项目名**，必填；选择文件后可自动带出去扩展名的文件名，仍可编辑。
2. **我想学到什么程度**，必填，多行；占位示例：“能独立写出一个小型 Agent，并讲清各模块如何协作”。
3. **选择主文件**，必填；拖拽区与“选择文件”按钮。
4. 辅助文案：“仅支持 EPUB、TXT、PDF、Markdown；每本书一个文件，本版不支持补充资料。”
5. 主按钮“导入并查看目录”；次按钮“取消”。

### 文件选中后

拖拽区变为文件卡片：文件名、格式、大小、“更换文件”“移除”。不支持的格式在提交前直接提示，不等待上传失败。

### 提交与进度

提交后留在本页，按钮改为“正在导入…”，出现分步状态：

```text
✓ 文件已保存
→ 正在解析正文与目录
○ 准备知识骨架
○ 自动目录规划（可跳过）
```

- 前两步失败：显示具体可读原因与“重试解析”“更换文件”。
- 自动目录规划失败：不显示为整个导入失败；以提示说明“已保留识别出的目录”，仍可进入书页。
- 一旦基础目录可用，主按钮变为“查看目录”，无需等待后续准备工作全部结束。
- 若文档没有可用结构，进入目录页的专门空态，不自动进行全文 AI 拆解。

### 异常与反例

- 重复点击不得生成两本书；
- 离开进度页后，可从我的书重新进入同一进度；
- 未配置文件服务不阻止基础目录识别；
- 不能创建无文件的新项目。

## P02 学习首页 `/`

### 页面目标

五秒内回答：**学哪本书、现在做什么、做完证明什么。**

### 默认布局

最大宽度 1080，内容顺序如下。

#### A. 页头

```text
今天该做什么                         2026-11-20 周五
[当前书：AI Agents in Depth ▾]
```

多书时选择器只切换“继续学习与全书进度”的当前书；今日任务可按当前书过滤，并明确是否还有其他书的任务。

#### B. 条件横幅

按优先级最多同时显示两条：

1. **长期中断回炉**：中断天数、建议动作、“查看方案”与“稍后处理”。
2. **逾期已重排**：数量与“查看变更”，展开后每行显示知识点名、原日期 → 新日期。

横幅不得显示内部编号，不得默认遮挡任务。

#### C. 当前书进度卡

左侧大数字“全书学透 32%”，下方“学透 3 / 9 章”；右侧两条进度：

- 学透进度：只含设为学透的章；
- 阅读进度：只含显式标记读完的章。

底部“口径与变化”链接，展开说明当前分母、最近一次强度或目录调整。没有可统计对象显示“—”，并解释原因。

#### D. 两个主动作

并排两卡，移动端上下排列：

- **继续上次**：知识点名、所属章、上次学到哪里、主按钮“继续学习”。没有历史时显示第一条今日任务。
- **今日复习**：到期数量、预计时间、主按钮“开始复习”。无到期卡显示“今天没有到期卡片”，不伪造任务。

#### E. 今日任务列表

每行包含：任务类型、知识点名、所属章、预计分钟、薄弱点标识（如有）、主操作“开始”。

- 点击整行与“开始”都进入对应学习上下文；
- “完成”不是主按钮，只有在对应学习动作完成后才可标记；
- 薄弱点任务可展开“为什么推荐”，显示关联错误证据；
- 已完成任务淡入“今天已完成”折叠区，不立即消失造成跳动。

#### F. 今日收束

有学习行为后显示摘要入口：“今天学了 2 个知识点，复习 8 张卡 → 查看摘要”。无行为不自动生成空摘要。

### 空态

| 情况 | 内容 | 主按钮 |
|---|---|---|
| 没有书 | “从一本书开始，先看到全书地图，再安排今天学什么” | 添加一本书 |
| 有书、目录未确认 | “先确认目录和各章强度，才能排出可靠计划” | 去整理目录 |
| 有目录、无计划 | “回答三个问题，生成第一份学习计划” | 做目标访谈 |
| 今日任务清空 | “今天的任务已完成。可以复习，或提前查看明天” | 去复习 / 查看计划 |
| 今日无任务但未来有计划 | 显示下一任务日期与内容 | 查看计划 |

## P03 我的书 `/studies`

### 页面结构

页头“我的书” + 主按钮“添加一本书”。下方标签“学习中 / 已归档”，默认学习中。

每本书一张横向卡片：

- 书名、学习目标（最多两行）、格式；
- 全书学透百分比或“不适用”；
- 当前章与下一步任务；
- 到期复习数；
- 最近学习时间；
- 主按钮“继续学习”，次按钮“管理”。

“管理”进入书页目录。卡片菜单含“归档 / 恢复”“导出学习数据”“删除”。删除整本书必须显示影响清单。

### 空态与旧项目

- 无书时使用与首页一致的添加引导，但保留我的书页头；
- 旧项目显示“旧版项目”徽标，不提供不适用的章级学透数字；
- 解析失败的书保留卡片，显示失败原因与“重试”，不得从列表消失。

## P04A 书页·目录 `/studies/:studyId/outline`

这是 V0.2 最重要的准备页面。

### A. 顶部摘要与主动作

```text
全书目录
12 章 · 178 个有效知识点 · 已排除 21 个非学习单元
[识别依据与规划记录]                         [生成学习计划]
```

已有计划时主按钮改为“查看计划”。次动作“重新规划目录”放在菜单中，不与学习计划争抢注意力。

### B. 状态条

按实际状态显示一种：

| 状态 | 文案与操作 | 树是否可操作 |
|---|---|---|
| 结构识别中 | “正在读取原书目录…” | 显示已识别部分 |
| 原文与引用准备中 | “原目录已可查看，正在准备可回跳的原文” | 可重命名、排除和设强度；拆分 / 合并等引用就绪后开放 |
| AI 规划中 | “正在根据目录整理学习单元，原目录仍可编辑” | 是 |
| 未配置 AI | “未配置 AI，已保留原书目录；可手动整理或稍后配置” | 是 |
| 规划失败 | “目录规划未完成，原目录未受影响” + 原因 + 重试 | 是 |
| 规划完成 | “已排除 18 项、拆分 6 处、合并 12 处” + 查看调整 | 是 |
| 低置信度 | “部分层级由标题样式推断，请检查标记节点” | 是 |

规划运行时禁用“重新规划”，但不禁用树编辑。AI 规划只在原文引用就绪后启动和应用；若编辑与规划结果冲突，保留用户最后操作并在记录中说明。

### C. 主工作区

桌面为左右两栏，左 42%、右 58%，最小高度为视口减去页头。

#### 左侧：树工具栏与目录树

工具栏第一行：搜索框“搜索目录”；第二行：展开全部、折叠到章、筛选“全部 / 待确认 / 已排除”。

树节点行高 36，包含：

1. 展开箭头；
2. 节点名称，最多两行；
3. 状态徽标：章、待确认、AI 调整、已排除；
4. 学透章的细进度条或完成勾；
5. 悬停出现的 `···` 编辑菜单。

章节点下方直接显示强度选择：“略读 / 读透 / 学透”，默认学透。修改后立即显示对计划与学透范围的影响，不伪装成无代价操作。

被排除节点保留在树中但置灰，可通过筛选隐藏；这样用户能恢复误排除内容。无来源节点显示“无原文”且不能进入学透统计。

#### 右侧：选中节点详情

未选择时显示全书说明与检查清单。选中后依次显示：

1. 面包屑路径；
2. 节点名称与状态；
3. **来源与识别**：原书目录 / 标题推断 / 用户修改 / AI 规划，附置信度与调整原因；
4. **学习目标**：可编辑摘要，说明学完能理解或做什么；
5. **学习数据**：预估时长、原文范围、卡片数、系统评估、自评；
6. **原文引用**：列出对应段落标题与页码或章节位置，点击回原文；
7. 主动作“开始学习”；章节点则显示“学习本章下一节”；
8. 编辑动作：重命名、新增子节点、拆分、合并、移动、排除 / 恢复、删除。

章详情额外显示：强度、方案覆盖、章内有效知识点数、已通过数、高风险卡数、暂停卡数、完成判定解释。

### D. 编辑弹窗

| 操作 | 弹窗必须包含 | 完成后的反馈 |
|---|---|---|
| 重命名 | 原名称、新名称 | 原位更新，保留原目录名称于调整记录 |
| 新增子节点 | 名称、学习目标、原文范围 | 选中并提示无来源时不进学透统计 |
| 拆分 | 原节点、原文范围、2–5 个新节点名称与各自范围 | 显示原关联数据如何保留，选中新节点 |
| 合并 | 当前节点、目标节点、合并后名称、双方卡片 / 测验 / 证据数量 | 明确“学习记录已合并，未删除证据”，必要时掌握状态回退 |
| 移动 | 目标位置、对顺序与计划的影响 | 树与计划预览同步更新 |
| 排除 / 恢复 | 排除原因、对计划和学透分母的影响 | 显示“有效知识点 N→M”，可撤销 |
| 删除 | 与排除的区别、不可恢复的关联影响 | 优先建议排除；确认后才删除 |

删除与合并不得用“整棵树重建”实现产品语义；用户必须看到既有卡片与证据被保留或明确失去什么。

### E. 调整记录抽屉

按时间列出：结构识别、AI 规划、用户编辑、强度变化。每条含时间、动作、原因、有效知识点和学透分母前后值。AI 调整可查看理由；用户编辑可撤销时提供“撤销”，无法撤销则说明限制。

### F. 无目录与异常空态

- **未识别出目录**：显示“这本书没有可用的标题结构”，提供“手动新增学习单元”“重新识别”“返回更换文件”。不自动全文拆解。
- **目录为空但正文可读**：仍可打开原文；生成计划按钮禁用并说明至少需要一个有原文的学习单元。
- **规划结果不理想**：可“恢复原目录”，恢复前显示将撤销哪些 AI 调整，不影响用户后续手动编辑。

## P05 书页·原文 `/studies/:studyId/source`

### 布局

左侧为可折叠章节目录，右侧为原文阅读区。顶部显示文件名、格式、解析状态与“下载原文件”。

阅读区支持：

- 章内连续滚动；
- 搜索书名内文本；
- 当前位置对应目录高亮；
- 从引用进入时，目标段落居中并高亮 3 秒；
- 页码或章节位置按原书可得信息显示，不伪造精确页码。

### 学习联动

选中一段文字后出现轻量操作：“就这段提问”“标记为卡壳”“保存为卡片”。

- “就这段提问”创建或恢复该知识点的学习会话，并带入选段；
- “保存为卡片”打开手建弹窗，背面预填选段，正面留空；
- 不提供“一键给本章批量制卡”。

### 异常

解析失败显示重试，不展示空白阅读器；原位置失效时回到所属章并说明。原文页不根据滚动或停留时间自动标记读完。

## P06 书页·计划 `/studies/:studyId/plan`

### A. 无计划：目标访谈

一页完成，不做冗长多轮聊天。

1. **目标**：默认带入项目目标，可改；
2. **希望何时完成**：日期选择，可不设；
3. **每天可投入**：分钟步进器，默认 45；
4. **各章强度**：按章列表批量设置，提供“全部学透”“全部读透”快捷操作，但不自动改单章覆盖；
5. 主按钮“生成计划草案”。

所有默认值在按钮上方汇总显示，跳过不等于隐藏。

### B. 计划草案

顶部显示“共 N 天 / 每天约 M 分钟 / 预计完成日期”。若期限装不下，显示明确警告：“按当前强度与时间，预计超出 12 天”，并提供“减少学透章”“增加每日时间”“延长期限”三种调整入口。

主体按日期分组，每组显示总分钟与任务：

- 类型、知识点、所属章、预计分钟；
- 改期、删除；
- 空白日可“添加任务”；
- 可上下调整同一天顺序。

底部主按钮“确认并开始”，次按钮“返回调整”。确认前不写为生效计划。

### C. 生效计划

页头显示当前进度、下一学习日、预计完成日，操作“添加任务”“调整目标”“查看变更”。

日期列表支持“本周 / 全部 / 逾期变更”筛选。每个任务支持改期与删除；新增任务时选择日期、知识点、类型和时长，类型受章强度限制。

“重新生成”不是一键覆盖：先展示新旧差异、将被替换的未完成任务和保留的历史，再由用户确认。

变更记录至少显示：生成、确认、手动增删改期、逾期重排、薄弱点插入、回炉。

### D. “我已掌握”快速验证

尚未自评的学透章有效知识点在任务菜单与档案树中显示“我已掌握”；已自评节点只显示“取消自评”，不重复发起验证。其他节点不显示该入口，并分别沿用略读读完或读透复述。

1. 点击后弹窗说明：“自评不等于系统通过，先用一道题快速验证”；当前任务不会被直接删除。
2. 确认后展示一道客观题与选项，此时自评仍为未标记，任务不跳过；提交前不显示答案和解析。出题失败、取消或未作答退出都保持原状态。
3. 通过：写入“已掌握”自评，显示“后续新计划可减少该知识点任务”，系统评估仍按既有证据计算。
4. 未通过：显示正确答案与来源，自评保持未标记；有生效计划时给出“已补回明天 / 指定日期”的真实任务入口，没有计划时说明会纳入下次计划。
5. 验证结果进入证据时间线；自评动作单独标记，不冒充系统通过。

## P07 学习会话 `/studies/:studyId/learn/:sessionId`

### A. 页头

```text
← 返回今天　第 4 章 / 4.2 上下文工程
[带我学 ▾]　[任务与完成说明]
```

页头始终知道当前书、章、知识点与任务。方案选择器只有“带我学 / 讲给我听 / 帮我过关”三项，切换即同时改变后续讲解风格与考练密度，不再另放一个会与之冲突的引导开关。自由提问会话显示“自由提问，不改变计划”。

### B. 桌面双栏

- 左栏 42%：原文面板，可折叠；显示当前知识点摘要、原文与引用位置；
- 右栏 58%：讲解、对话、测验与输入区；
- 左侧引用点击不跳走，右侧引用与左侧原文联动；
- 窄屏改为“学习 / 原文”两个顶部页签，输入区始终可用。

### C. 开场

进入知识点学习后，首条 AI 消息自动出现：

1. 一句话说明本点要解决什么；
2. 第一段完整讲解，带 `[1][2]` 引用；
3. 一个简短理解问题或下一步，不一次塞入整章。

首条消息下提供三步引导：“读原文 → 问不懂 → 考一组”，可关闭且记住偏好。加载失败保留原文和“重新生成讲解”。

### D. 对话与操作

消息支持分段 Markdown、代码块与引用。用户输入区为多行，Enter 发送、Shift+Enter 换行；生成中可停止。

输入区上方固定动作：

- 考我一组；
- 你来讲，我挑错（费曼）；
- 保存卡片；
- 查看掌握证据。

对话中每条 AI 消息的菜单含“复制”“就这段追问”“标记卡壳”。标记卡壳后打开卡片弹窗，预填相关内容，由用户确认，不静默批量生成。

### E. 内嵌测验

点击“考我一组”后，在对话流中插入测验卡，不另开页面。

未作答：题号、题型、题干、选项或简答框、“提交答案”。提交前不显示答案。

已作答：

- 显示对错、正确答案、解释与来源；
- 简答题显示具体评语，而非只给分数；
- 错题出现“已自动形成复习卡”与“查看卡片”；
- 操作“回到原文”“再问一个变式”“继续学习”。

重复点击生成题目时需避免同题重复。略读章不显示“考我一组”；读透章只提供章末复述。

### F. 费曼复述

复述区域提示：“合上讲义，用自己的话讲清这部分。AI 会追问并指出缺漏。”

至少一次追问后才给通过建议；结果页包含“讲清了什么 / 缺漏 / 推荐回看原文 / 是否通过”。读透章的通过状态可在章详情回查。

### G. 完成与离开

“任务与完成说明”区分：

- 任务是否完成；
- 知识点系统评估；
- 章是否完成。

用户可以直接离开，未完成任务仍在计划里；系统不得因为打开过会话就自动标记掌握。

## P08 复习 `/review`

### A. 开始状态

页头“复习” + 书选择器 + 今日到期数。副区域显示“今日上限 20，可在设置调整”。

首张卡只显示正面、所属知识点与来源章，不显示背面。主按钮“显示答案”，空格键同效。

### B. 答案与评分

显示答案后展开背面与来源，底部四档：

```text
1 忘了　<1 天　　2 困难　2 天　　3 良好　5 天　　4 轻松　12 天
```

时间为示例位，实际显示本次将安排的时间。快捷键 1–4；评分后进入下一张，顶部显示“还剩 N 张”。

“忘了”的卡当天会再次出现，队列需明确“稍后再见”，不能给用户造成评分无效的错觉。

### C. 辅助操作

- 查看源文：侧抽屉打开，不丢失当前卡；
- 编辑：修改正反面，不改历史评分；
- 暂停：说明不再出队，可随时恢复；
- 删除：二次确认。

### D. 空态与结束

- 无到期卡：“这本书今天没有到期卡片”，给“返回今天”；
- 达到每日上限但仍有到期：说明上限并提供“调整上限”；
- 完成本轮：显示复习数、各评分数量、仍薄弱的知识点和下一步，不自动制造新卡。

## P09 卡片 `/cards`

### A. 页头与筛选

主按钮“新建卡片”，次按钮“导出 Anki”。第二行筛选：书、知识点、来源、状态、搜索。

知识点筛选使用可搜索树，包含所有叶子与中间节点；选中间节点表示包含后代。筛选后显示结果数，清空筛选一键可见。

### B. 列表

每行：正面摘要、知识点、来源（答错 / 卡壳标记 / 手建）、状态、下次复习、记忆风险、操作。

点击行打开详情抽屉：完整正反面、来源原文、历史评分、编辑、暂停 / 恢复、删除。

### C. 新建 / 编辑弹窗

字段：所属书（新建时默认当前筛选书）、所属知识点、正面、背面、来源段落（可选）。保存后出现在列表并可被复习检索；未选知识点或正反面为空时禁止提交。

编辑不重置到期时间与历史评分，界面明确说明。

### D. 导出

点击后直接触发文件下载；按钮状态为“正在导出…”，完成后显示“已导出 N 张卡”。若 0 张，禁用并说明当前筛选无卡片。下载内容不含密钥。

## P10 掌握档案 `/mastery`

### A. 顶部总览

书选择器后显示：全书学透百分比、学透章数、阅读进度、高风险卡数。每项旁有“口径”说明与下钻入口。

百分比变化若由目录或强度调整引起，在数字下显示：“因排除 2 个非学习节点，统计范围由 182 调整为 180”。掌握回退则显示：“因 3 张记忆卡风险升高，2 个知识点退出有效通过，第 4 章与全书进度同步回退”。“口径”中明确：全书分子与学透章完成都看有效通过，历史测验通过记录不会因风险被删除。

### B. 章进度

章列表每行：章名、强度、有效知识点、有效通过数、仅因风险未计入数、高风险卡、完成状态。点击章后下方树定位到该章。

### C. 知识点树表

保留目录层级，每行显示：

- 名称；
- 系统评估：未学 / 学习中 / 已通过 / 薄弱；
- 自评：未标记 / 已掌握；
- 最近证据时间与类型；
- 卡片风险；系统为已通过但存在高风险时显示“测验已通过，记忆待巩固”，不计为有效通过；
- 操作“证据”；学透章有效知识点另提供“我已掌握 / 取消自评”，交互见 P06-D。

支持按系统评估、强度、风险筛选。无来源与已排除节点有独立标识，不混入通过统计。

### D. 证据抽屉

顶部同时显示系统评估与自评，明确二者不同。时间线每项包含：日期、测验 / 复习 / 复述、结果、题目或评分摘要、“查看原文”。

掌握回退也作为时间线事实展示，不删除旧通过记录。

### E. 报告

“导出学习报告”始终可导出当前真实进展；达到结业条件时额外显示“查看结业报告”。两者都必须真实下载 Markdown 文件。

## P11 摘要与复盘 `/summaries`

页头含书选择器，标签“每日摘要 / 周复盘”。

- 每日摘要按日期倒序：学习知识点、测验结果、成卡数、复习数、明天第一件事；
- 周复盘包含完成率、掌握变化、持续薄弱点、遗忘风险和计划建议；
- 无行为日期不生成空摘要；
- 建议旁的“应用到计划”先展示差异，再确认；
- 无数据时写“这周还没有足够学习记录”，不编造鼓励或建议。

## P12 设置 `/settings`

按以下顺序分节，每节独立保存：

1. **讲解与测验服务**：地址、模型、密钥；密钥掩码、替换与清除；
2. **资料处理服务**：用于准备原文检索的服务配置；未配置或不可用时，已识别目录、计划与已有学习记录仍可查看，依赖原文检索的讲解和提问可能受限；
3. **复习偏好**：每日上限、长期中断阈值；高级参数折叠展示实际值与解释；
4. **数据**：全量导出、备份说明、原文件与派生数据范围；
5. **用量**：按日期与场景显示请求和用量，可切换日期范围；
6. **危险操作**：清除配置与删除数据的入口分开，删除数据需强确认。

保存密钥后只显示掩码；导出与日志不得含明文。配置失败不清空用户刚填写的其他项。

## P13 旧版项目形态

旧项目继续使用原资料、知识点、计划、会话、卡片、复习和档案，但：

- 书页显示“旧版项目，不提供新的章级学透统计”；
- 学透百分比位置显示“不适用”，不是 0%；
- 不为了适配新界面批量重建目录或删除旧证据；
- 若提供“整理为新目录”，必须是显式动作，先展示影响并保留既有学习记录；
- 本版不承诺把旧多资料项目自动迁移为单主文件项目。

## 学习方法抽屉（全站）

右侧抽屉宽 480，标题“这些方法为什么在产品里”。每张方法卡只有“大白话 + 产品里在哪里 + 一句依据”：

| 方法 | 文案 |
|---|---|
| 先答再看 | 先自己回答，再看反馈；“想起来”比“再看一遍”更能暴露真实掌握。出现在知识点测验。 |
| 快忘时复习 | 在记忆将忘未忘时重现，逐步拉长间隔。出现在今日复习与四档评分。 |
| 你讲我挑错 | 用自己的话讲，讲不清的地方就是缺口。出现在费曼复述。 |
| 过关才前进 | 通过考练才算系统掌握，没通过就补练。出现在掌握档案与薄弱点任务。 |
| 引导你思考 | 先给提示，让你自己走完推理；也可切到直接讲解。出现在带我学方案。 |
| 直接讲给我 | 时间紧或只需理解时，直接给清楚解释，不强行绕弯。出现在讲给我听方案。 |

科学依据用简短说明与来源名称，不在主界面堆研究术语。

## 14. 逐页验收走查表

每次里程碑收尾，至少人工或 E2E 走查以下真实结果：

- [ ] 添加一本书后不会产生空项目，四种格式与失败态都有明确结果；
- [ ] 未配置 AI、AI 失败和超时都能看到并编辑原目录；
- [ ] 目录排除、拆分、合并、移动后，关联学习记录符合弹窗承诺；
- [ ] 首页能直接进入学习，逾期提示有真实名称与日期；
- [ ] 会话首条讲解有引用，引用回到当前书正确位置；
- [ ] 错题确实成卡，次日能复习，评分确实改变队列；
- [ ] 卡片筛选覆盖叶子，手建、编辑、暂停、删除都生效；
- [ ] Anki 与报告都下载到真实文件；
- [ ] 学透百分比能下钻证据，高风险与分母变化能造成可见回退或说明；
- [ ] 计划可增删改期，重新生成不会静默覆盖；
- [ ] 全局页切换书后，统计和操作对象一致；
- [ ] 全程无写死书籍地址、无裸内部编号、无未解释技术术语。
