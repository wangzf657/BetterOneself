## 1. 全局结构

```
顶栏:BetterOneself · [项目切换器] · 复习入口(角标=到期数) · 设置
└── 左侧栏:随上下文(项目内 tab / 全局页导航)
```

- **首页即今日任务**(M5-01):`/` 直接呈现当日该做的事,不是仪表盘
- 项目内页面挂 `/studies/:id/*`,tab 次序=用户旅程次序:资料 → 知识点 → 计划 → 复习 → 卡片 → 档案 → 摘要
- 全局页:今日 `/`、复习 `/review`、项目列表 `/studies`、设置 `/settings`

## 3. 三张主战场页展开

### 学习会话 `/studies/:id/learn/:taskId`(最高频,专注模式)

```
┌────────────────────────────────────────────────┐
│ 任务头:知识点名 · 任务类型 · 苏格拉底开关       │
├──────────────────────────────┬─────────────────┤
│ 对话流(主区)                 │ 源文侧栏(可收起) │
│  · 讲解分段渲染(认知负荷)     │  当前引用的 chunk │
│  · 回答带引用角标[n]          │  高亮定位,可滚   │
│  · 测验卡内嵌:客观题选项 /    │  到上下文        │
│    简答输入框+AI评语          │                 │
│  · 错题反馈含"回看源文"按钮    │                 │
├──────────────────────────────┴─────────────────┤
│ 输入区:提问框 · "存为卡片"按钮 · 自由提问入口   │
└────────────────────────────────────────────────┘
```

- 引用角标:悬停预览摘要,点击打开右侧栏定位(全站统一交互)
- 苏格拉底开关(M3-03):会话级,引导模式下用户直接要答案 → 先给一层提示
- 错题自动沉淀提示:"已生成 1 张复习卡片"轻量 toast(M3-05)
- 自由提问(M3-06):同页切线程,回答带引用、不改变当日计划

### 复习 `/review`(最高频,碎片模式 3-10 分钟)

```
当前卡片正面(大字) → [空格/点击翻面]
背面:答案 + 源引用(可点开侧栏)
四档评分:[1 忘了] [2 困难] [3 良好] [4 轻松](键盘 1-4)
顶部:进度 3/20;"忘了"的卡片今日重现提示
```

- 完成态/无到期:"今日无复习,看看今日任务"(M4-01)
- 单卡流程零跳转,键盘可完成全部操作

### 今日任务 `/`(首页)

- 打开即答案:"今天该做什么"(M5-01);有逾期时最顶部横幅展示重排结果并可展开明细
- 任务行:类型徽标(学习/薄弱点复习/费曼)、预计时长、知识点名;点击直达会话
- 薄弱点任务(M5-04):"针对薄弱点"标识,展开显示证据(哪次答错)

## 4. 跨页交互约定

| 约定 | 说明 | 需求 |
|---|---|---|
| 引用角标 | 全站统一:`[n]` 悬停预览 → 点击开侧栏定位源文 | M2-01, M3-02 |
| 状态徽标 | 解析中(轮询)/ 就绪 / 失败;掌握状态四色 | M1-06, M6-01 |
| 危险操作 | 删除资料/知识点/卡片/项目:确认弹层,说明关联影响 | M1-05, M2-03 |

| 后台任务 | 解析/生成中不阻塞页面,状态徽标轮询更新 | M1-06 |
